# 全书路线图

全书按「不先用后讲」排：每个定义、定理、技巧，第一次被用到之前都已经讲过。书序是 Z → C → L → P → M → K。
每章标主线或支线，支线以了解为主；Z 和 K 两部分不分主线支线。

## 六个部分之间的引用

箭头从被引用的部分指向引用它的部分，数字是后面部分引用前面部分的节数。
