## K4.2 · 综合测验（速记）

| 提示 | 内容 |
|---|---|
| 分钟分值 | 每个动作都问：这一分钟花在这里，比花在别处多得还是少得。测验一的预算：扫卷 8 + 选择 40 + 解答 84 + 检查 18 = 150 分钟；选择题 1 分/分钟（每题 4 分钟是估值，做过几套后换成自己的实际用时），解答题约 0.71 分/分钟 |
| 放弃线 | 一道 4 分的选择题超过约 6 分钟就放弃；任何题用掉预算的 1.5 倍仍无进展，写下已有的，打记号，换下一题 |
| 三遍扫卷 | 第一遍只读题并标 ✓（一眼看出方法）、△（有思路要算）、×（没思路）；第二遍先 ✓ 后 △；第三遍做 ×，并留 15 分钟检查 |
| 特殊值与排除 | 「恒成立」的选项，一个反例杀死一个选项；反例选得让不同选项各自露馅；剩下的才是答案，不能拿特殊值去「证」一个选项 |
| 极端情形 | 带参数的公式，取概率 0、1、$\tfrac12$ 和 $n=1,2,3$ 检验；一个极端值分不开，就换一个 |
| 形状检验 | 矩阵求导和乘积先写形状：$\partial L/\partial W$ 与 $W$ 同形；$L=\lVert XW-Y\rVert_F^{2}$ 时 $\partial L/\partial W=2X^{\mathsf T}(XW-Y)$ |
| 四层写法 | 设、条件、推理（每个等号配依据）、结论；定理的前提要核对，例如「实对称」保证特征值是实数 |
| 候选点加存在性 | 最值题：闭有界加连续保证最值存在；乘子法要求 $\nabla g\ne\boldsymbol0$；列出全部候选点并比较函数值 |
| 参数分类 | 先求使情形变化的特殊值（方程组看系数行列式为 0），其余参数一种情形，特殊值逐个代回并再按另一个参数分；不重不漏 |
| 做不完时 | 分段写独立小结论；用「若……则……」写条件形式并注明「尚需证明」；不要把没证的当成已证 |
| 复盘五类错因 | 概念、方法、过程、计算、时间；先找第一处出错的一步，再写「看到什么信号用什么方法」，一周后重做原题 |
| 复盘次序 | 先补不用学新东西的类别（过程、计算），再补要回去重学的（概念）；丢分多少只是参考；先确认过程类确实是会做没写 |
| 洛必达的条件 | 分母的导数不为 0 且导数之比的极限存在或为无穷大才能下结论；条件不满足时，只说明这个方法不适用，原极限可能仍然存在，例如 $\lim_{x\to\infty}\frac{x+\sin x}{x-\sin x}=1$ |
| 检查单 | 回答了问题吗；「不」「一定」「恒成立」读对了吗；代回验算；参数特殊值；证明的依据；最值的存在性；答案位置 |
