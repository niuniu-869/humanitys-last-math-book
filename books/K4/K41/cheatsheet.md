## K4.1 · 探索题与数学素养（速记）

| 提示 | 内容 |
|---|---|
| 特殊化（方法 1） | 一般情形复杂时，让变的量取 $1,2,3,4$，列表、看差或比、猜规律，最后用结构理由或归纳法证明；只有表格不是证明 |
| 规律会骗人 | 圆周上 $n$ 点任意三条弦在圆内不共点分圆：$1,2,4,8,16$ 后是 $31$，块数 $=1+\binom n2+\binom n4$；$n^2+n+41$ 在 $n=40$ 时不是质数 |
| 加线增块 | $n$ 条直线（两两相交、三线不共点）：$f(n)=f(n-1)+n$，$f(n)=1+\frac{n(n+1)}2$；新线被分成的段数就是新增的块数 |
| 不变量（方法 2） | 写清一次操作 → 猜量（和、奇偶、模 $m$ 余数、乘积、染色之差）→ 核对每种操作 → 比较起点与目标；值不同则目标不可达，值相同还需另外构造或论证，也可用来确定终值 |
| 常见的不变量 | 擦两数写差：和的奇偶；写 $a+b+ab$：$\prod(x+1)$；骨牌：黑白格之差；三类球 $(-1,-1,+2)$：两类之差 $\bmod3$ |
| 单调量（方法 3） | 整数、非负、严格减小三条缺一不可（$1,\tfrac12,\tfrac14,\dots$ 就不停）；满足时必停；每步恰减 1 ⇒ 步数 $=\Phi_{\text{起}}-\Phi_{\text{终}}$；交换相邻的逆序一对时，逆序对数恰减 1，①需换 7 次 |
| 倒推（方法 4） | 从目标往回退，标记“轮到谁谁输”的局面；每次取 $1\sim m$ 颗、取走最后一颗者赢时，必输局面是 $m+1$ 的倍数；配对 $t\leftrightarrow m+1-t$ 靠的是每次可取 $1\sim m$ 颗；再用正向话说一遍 |
| 加 1 乘 2 | 从 1 出发加 1 或乘 2 到 $N$，倒推：目标大于 1 时奇数减 1、偶数除以 2，到 1 停止；$N=100$ 需 8 步 |
| 取反（方法 5） | “至少一个”算 $1-P(\text{一个也没有})$；6 项，每项取值 $1,\dots,12$，至少两项相同：$1-\frac{12\cdot11\cdot10\cdot9\cdot8\cdot7}{12^6}\approx0.777$；分析法每步必须是“$\Longleftarrow$”，且要用到 $a,b>0$ 这类条件 |
| 建模四步（方法 6） | 假设 → 变量 → 关系 → 检验，检验里要改一个假设看结论变不变；间隔 $g_i$ 在有限重复周期内均匀到达时的平均等车时间 $\sum g_i^2/(2\sum g_i)$ |
| 幂律拟合 | $T=cn^b$ 取对数成直线 $\log T=\log c+b\log n$；斜率 $b$ 是规模翻倍时用时的指数，外推要说明范围 |
| 三遍读法（方法 7） | 一找问题，二标定义与符号（列符号表），三对公式（符号、形状、含义、改参数），再用最小的数字例子代进去 |
| 吃透新定义（方法 8） | 最小正例、最小反例、边界与退化、用自己的话改写；$k$-逆序对 $I_k$ 随 $k$ 增大不增，①的 $I_1,I_2,I_3=7,6,5$ |
| 四类小问（方法 9） | 计算：代入并保留精度；推导：一边出发、每步写依据；参数变化：先写成字母重走一遍；数据检验：改成可验证的命题，确定性看误差，随机性做假设检验 |
| 限时 20 分钟（方法 10） | 读 4 分钟、做 12 分钟、回头检查 4 分钟；卡住超过 4 分钟先写已有的思路并跳到下一问 |
