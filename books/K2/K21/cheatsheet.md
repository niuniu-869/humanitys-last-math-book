| 提示 | 内容 |
|---|---|
| 列递推 | 设 $a_n$ 为规模 $n$ 的答案；盯住最后一步（或最大的元素）分类；分类用加法、分步用乘法；初值个数等于阶数，递推加初值唯一确定数列；再用小 $n$ 手数核对 |
| 三个标准递推 | 爬楼梯（1 或 2 级）$a_n=a_{n-1}+a_{n-2}$；汉诺塔 $h_n=2h_{n-1}+1$；错排 $D_n=(n-1)(D_{n-1}+D_{n-2})$ |
| 一阶 $a_n=qa_{n-1}+c$ | 不动点 $x^*=\dfrac{c}{1-q}$（$q\ne1$），$a_n=x^*+q^n(a_0-x^*)$；与不动点的差每步乘 $q$ |
| $q=1$ | $a_n=a_{n-1}+f(n)$ 用累加，$a_n=a_0+f(1)+\cdots+f(n)$ |
| 二阶特征方程 | $a_{n+2}=pa_{n+1}+qa_n$ 的特征方程是 $\lambda^2=p\lambda+q$；试 $a_n=\lambda^n$ 得来；这里的 $q$ 是二阶系数，与一阶递推的乘数 $q$ 无关 |
| 两个不同的根 | $a_n=C_1r_1^n+C_2r_2^n$，用前两项定 $C_1$、$C_2$，再用第三项验算 |
| 斐波那契 | $F_n=\dfrac{1}{\sqrt5}(\varphi^n-\psi^n)$，$\varphi=\dfrac{1+\sqrt5}{2}$，$\psi=\dfrac{1-\sqrt5}{2}$；$F_n$ 是离 $\varphi^n/\sqrt5$ 最近的整数 |
| 矩阵的写法 | $\boldsymbol x_n=(a_{n+1},a_n)^{\mathsf T}$，$A=\begin{pmatrix}p&q\\1&0\end{pmatrix}$，特征方程相同；$A^n=\begin{pmatrix}F_{n+1}&F_n\\F_n&F_{n-1}\end{pmatrix}$ |
| 二重根 | 特征方程有二重根 $r\ne0$：$a_n=(C_1+C_2n)r^n$；只有一个幂解配不出任意初值，所以要多乘一个 $n$ |
| 非齐次 | 通解 = 齐次通解 + 一个特解；特解按 $f(n)$ 的形式设，若设的形式已是齐次的解，单根乘 $n$、二重根乘 $n^2$ |
| 易错 | 先用初值定齐次系数再加特解（应最后用初值）；汉诺塔、错排漏掉系数；把初值个数少给 |
