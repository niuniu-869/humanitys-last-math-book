| 提示 | 内容 |
|---|---|
| 图与度 | 图由点集 $V$ 和边组成；度 $\deg v$ = 与 $v$ 关联的边数；简单图无环无重边；$K_n$ 有 $\binom n2$ 条边 |
| 握手定理 | $\sum\deg v=2m$（数「点—边对」）；奇度点个数一定是偶数；$7$ 个人各有 $3$ 个朋友不可能 |
| 途径、路径、圈 | 途径点边可重复；路径点不重复；圈起终点相同、其余点不重复；有途径就有路径；距离 $d(u,v)$ = 最短路径长 |
| 分层法 | 起点第 0 层，第 $k+1$ 层 = 与第 $k$ 层相邻且不在第 0 到第 $k$ 层的点；层号 = 距离；没被分到 = 不连通 |
| 边多必连通 | $n$ 点简单图，$m>\binom{n-1}2$ 则连通（$n=7$：$m\ge16$） |
| 一笔画 | 去掉孤立点后连通：奇度点 0 个 ⇔ 有欧拉回路；奇度点 0 或 2 个 ⇔ 有欧拉路径，2 个时必须从一个奇度点出发、到另一个结束；$2k$ 个奇度点（$k\ge1$）至少 $k$ 笔 |
| 欧拉与哈密顿 | 欧拉：每条边一次，去掉孤立点后验连通，再数奇度点（两个不相连的三角形度全为偶，却不能一笔画）；哈密顿：每个点一次，没有简单判据 |
| 树 | 连通且无圈；$n$ 点恰 $n-1$ 边；点数 $\ge2$ 时至少 2 片叶子；删叶子仍是树；任意两点恰一条路径；森林 $m=n-c$ |
| 树的等价说法 | 连通 + $m=n-1$，或无圈 + $m=n-1$，二者缺一个条件就不一定是树（三角形加孤立点） |
| 二叉树 | 第 $d$ 层至多 $2^d$ 点；高 $h$ 至多 $2^h$ 片叶子，$n$ 片叶子需 $h\ge\lceil\log_2n\rceil$；满二叉树叶子 = 内部点 + 1；从有根树起，叶子 = 没有子女的点 |
| 邻接矩阵 | 无向简单图：对称 0/1 矩阵，行和 = 度；$(M^k)_{ij}$ = 长为 $k$ 的途径数（不是路径）；$(M^2)_{ii}=\deg i$，$\operatorname{tr}M^3=6\times$三角形数 |
| 二分图 | 可分成 $X,Y$ 使边都在两组之间 ⇔ 无奇圈；分层后按层号奇偶分组；二分图至多 $\lfloor n^2/4\rfloor$ 条边 |
| 关系 | 自反 / 对称 / 传递；三者齐 = 等价关系，分成互不相交的等价类；自反 + 反对称 + 传递 = 偏序；等价关系三条缺一不可，缺哪条等价类都会出错 |
