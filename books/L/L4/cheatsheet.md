## L.4 · 高斯消元（速记）

| 提示 | 内容 |
|---|---|
| 增广矩阵 | $(A\mid\boldsymbol{b})$：一行一个方程，竖线后是常数项 |
| 初等行变换 | $r_i\leftrightarrow r_j$；$kr_i$（$k\ne0$）；$r_i+kr_j$。都能撤销，所以不改变解；解方程组不用列变换 |
| 行阶梯形 | 零行在最下；每行主元（第一个非零数）在上一行主元的右边 |
| 行最简形 | 阶梯形 + 主元都是 1 + 主元列其余全 0；唯一，与消元路线无关 |
| 方阵 | $n$ 阶方阵：$n$ 个主元 ⇔ 行最简形是 $E$ ⇔ 每个 $A\boldsymbol{x}=\boldsymbol{b}$ 唯一解 ⇔ $A\boldsymbol{x}=\boldsymbol{0}$ 只有零解 |
| 三种说法 | 有解 ⇔ $\boldsymbol{b}$ 是列的组合 ⇔ $\boldsymbol{b}$ 在像里；有自由未知量 ⇔ 有方向被压到原点 |
| 无解 | 阶梯形里出现 $(0,\dots,0\mid d)$，$d\ne0$ |
| 唯一解 / 无穷多解 | 有解时：主元个数 = 未知数个数 → 唯一；< 未知数个数 → 无穷多（自由未知量任取） |
| 写全部解 | 自由未知量设参数，主元未知量移项表示，写成「常数向量 + 参数 × 向量」，代回检验 |
| 含参数 | 只用不含字母的行去消，别除以可能为 0 的式子；最后看末行 $(\cdots\mid\cdots)$ 分情况 |
| 齐次方程组 | 总有零解；有非零解 ⇔ 有自由未知量；未知数多于方程必有非零解 |
| 初等矩阵 | 对 $E$ 做一次初等变换得到；$E(i,j)$、$E(i(k))$、$E(i,j(k))$（$(i,j)$ 位置是 $k$） |
| 左乘与右乘 | 左乘做行变换，右乘做列变换；$E(i,j(k))$ 左乘是 $r_i+kr_j$，右乘是 $c_j+kc_i$ |
| 连做几步 | 左乘时先做的在右边（$E_s\cdots E_1A$）；右乘时先做的在左边 |
| 撤销 | $E(i,j)E(i,j)=E$，$E(i(\frac1k))E(i(k))=E$，$E(i,j(-k))E(i,j(k))=E$；用②核对左右乘 |
