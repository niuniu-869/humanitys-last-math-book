## C.19 · 空间向量与解析几何（答案）

### A 基础

**C19-01**
**答案：** $M=(2,-1,1)$，$d(A,M)=\sqrt3$。设 $M=(x,y,z)$，因为终点减起点给出位移，所以条件是 $(x-1,y+2,z)=(3-x,-y,2-z)$，解得上述坐标。于是 $\overrightarrow{AM}=(1,1,1)$，长度为 $\sqrt3$。

区分点：两个位移的起点不同，必须分别用终点减起点，不能把条件误写成两点到原点的距离相等。

**C19-02**
**答案：** 选 B。因为第三个方向余弦的平方为 $1-9/25-16/25=0$，所以它只能为 0；再用长度乘方向余弦，得到 $(3,4,0)$。

A 错在把正负号当成必有两个不同值，而且所列向量的长度都不是 5。B 满足长度和两个方向条件。C 给的是单位向量，遗漏了长度 5。D 把平方和为 1 错当成余弦之和不超过 1。

区分点：平方方程的右边为 0 时，正负两种写法重合，不能机械地断言有两个向量。

**C19-03**
**答案：** 选 C。计算得 $\boldsymbol{a}\cdot\boldsymbol{b}=1-1=0$，$\boldsymbol{a}\times\boldsymbol{b}=(-1,2,1)$。

A 错，因为两个向量都非零，数量积为零只说明它们垂直。B 错，因为向量积为零对应平行。C 的两个判断均成立。D 错，因为 $\sqrt6$ 是平行四边形面积，三角形面积为 $\sqrt6/2$。

区分点：先分清数量积与向量积各在判定什么，再判断面积是否需要除以 2。

**C19-04**
**答案：** $u=-3$，夹角为钝角。因为投影方向是 $\boldsymbol{a}$，所以投影长为 $2u/2=u$。令它等于 $-3$ 得 $u=-3$；此时数量积为 $-6<0$，所以夹角为钝角。

区分点：投影公式的分母是投影方向的长度，投影的负号也不能去掉。

**C19-05**
**答案：** 选 B。方向向量 $(1,-1,0)$ 与法向量 $(1,1,0)$ 垂直，而且代入任意参数都有 $x+y=1+t-t=1$，所以整条直线在平面内。

A 错在只查方向便排除了公共点。B 由恒等式成立。C 混淆了方向向量和法向量，线面垂直要求它们平行。D 只代入了 $t=0$，漏掉其余无穷多个公共点。

区分点：数量积为零不能单独判定直线与平面没有公共点，还须代入直线上的点。

### B 进阶

**C19-06**
**答案：** $\lVert\boldsymbol{a}-\boldsymbol{b}\rVert=\sqrt7$，$\lambda=1/6$。先展开已知的长度平方：

$$19=4+9+2\boldsymbol{a}\cdot\boldsymbol{b},$$

所以 $\boldsymbol{a}\cdot\boldsymbol{b}=3$，从而差向量的长度平方是 $4+9-6=7$。再展开垂直条件：

$$(\boldsymbol{a}+\lambda\boldsymbol{b})\cdot(\boldsymbol{a}-\boldsymbol{b})=4-3+\lambda(3-9)=1-6\lambda=0.$$

于是 $\lambda=1/6$。两个原向量的数量积绝对值小于长度之积 6，故不平行，上述两个组合也都非零。

区分点：没有坐标时仍可从长度平方恢复数量积，再用分配律处理组合向量的垂直条件。

**C19-07**
**答案：** 令 $\boldsymbol u=\overrightarrow{AB}$、$\boldsymbol v=\overrightarrow{AD}$。则两条对角线的方向分别是 $\boldsymbol u+\boldsymbol v$ 与 $\boldsymbol v-\boldsymbol u$，它们的数量积为

$$
(\boldsymbol u+\boldsymbol v)\cdot(\boldsymbol v-\boldsymbol u)=\lVert\boldsymbol v\rVert^2-\lVert\boldsymbol u\rVert^2.
$$

由于 $\boldsymbol u,\boldsymbol v$ 不平行，两条对角线都非零，所以对角线垂直当且仅当 $\lVert\boldsymbol u\rVert=\lVert\boldsymbol v\rVert$，也就是 $d(A,B)=d(A,D)$。这只能说明平行四边形是菱形，不能推出正方形。例如

$$A=(0,0,0),\ B=(2,0,0),\ C=(3,\sqrt3,0),\ D=(1,\sqrt3,0).$$

两条邻边都长 2，而 $\overrightarrow{AB}\cdot\overrightarrow{AD}=2\ne0$，所以不是正方形。

区分点：把对角线改写成邻边的和与差，再区分“菱形”与“正方形”。

**C19-08**
**答案：** 四点共面当且仅当 $t=1$；体积为 $1/3$ 当且仅当 $t=-1$ 或 $t=3$。三个位置向量有公共起点 $O$，其混合积为

$$\begin{vmatrix}1&0&1\\0&1&1\\1&t&2\end{vmatrix}=(2-t)-1=1-t.$$

令混合积为 0 得 $t=1$。四面体体积为 $|1-t|/6$，所以体积条件给出 $|1-t|=2$，解得另外两个值。

区分点：共面条件直接令混合积为零，体积条件却要先取绝对值，不能漏掉另一侧的解。

**C19-09**
**答案：** $\pi:x-z+1=0$，原点到它的距离为 $1/\sqrt2$。

直线的两个平面法向量为 $(1,1,0)$、$(0,1,1)$，所以方向可取 $\boldsymbol{s}=(1,-1,1)$。令 $y=0$，得到线上一点 $M=(1,0,2)$。

所求平面的法向量必须垂直于 $\boldsymbol{s}$，还必须垂直于 $\sigma$ 的法向量 $(1,1,1)$，故可取

$$\boldsymbol{n}=\boldsymbol{s}\times(1,1,1)=(-2,0,2).$$

点法式为 $-2(x-1)+2(z-2)=0$，化简即得 $\pi$。距离为 $|1|/\sqrt{1+1}=1/\sqrt2$。两个已知方向不平行，因此所求法向量的方向唯一。

区分点：包含一条直线限制的是平面法向量与直线方向的关系，不能直接把直线方向当成平面法向量。

**C19-10**
**答案：** 曲面为 $x^2+y^2=(z-1)^2$、$z\ge1$，是顶点在 $(0,0,1)$ 的圆锥面的上半部分。$z=0$ 没有截痕，$z=2$ 截出半径为 1 的圆。

原射线上横坐标非负，到 $z$ 轴的距离就是原横坐标，因此旋转后满足

$$z=1+\sqrt{x^2+y^2}.$$

移项平方得到上述二次方程，同时必须保留 $z\ge1$。在 $z=2$ 时，截痕为 $x^2+y^2=1$、$z=2$；$z=0$ 违反范围条件，不能从平方后的方程读出一个实际存在的圆。

区分点：平方会掩盖原射线的范围，认出圆锥面之后仍须排除多出来的下半部分。

### C 提高

**C19-11**
**答案：** 两直线异面，$\pi:-x+2y+z=0$；最小距离为 $1/\sqrt6$，在 $P=(1/2,0,1/2)\in L_1$、$Q=(1/3,1/3,2/3)\in L_2$ 时取到。

取两个方向 $\boldsymbol{s}_1=(1,0,1)$、$\boldsymbol{s}_2=(1,1,-1)$，则

$$\boldsymbol{n}=\boldsymbol{s}_1\times\boldsymbol{s}_2=(-1,2,1),\qquad \boldsymbol{n}\cdot(1,1,0)=1.$$

混合积非零，所以两直线异面。过原点、以 $\boldsymbol{n}$ 为法向量的平面包含 $L_1$；将 $L_2$ 代入平面左边恒得 1，所以 $L_2$ 与该平面平行且不在其中。其上每一点到平面的距离都是 $1/\sqrt6$，因此任意连接两直线的线段长度都不小于这个数。

要验证下界能取到，设 $P=(t,0,t)$、$Q=(1+u,1+u,-u)$。令连接向量同时垂直于两个方向，得到

$$\overrightarrow{PQ}\cdot\boldsymbol{s}_1=1-2t=0,\qquad \overrightarrow{PQ}\cdot\boldsymbol{s}_2=2+3u=0.$$

于是 $t=1/2$、$u=-2/3$，得到答案中的两点。此时 $\overrightarrow{PQ}=(-1,2,1)/6$，长度恰为 $1/\sqrt6$，所以下界确实达到。

区分点：辅助平面先给出距离下界，还要找到达到下界的两点，才能把它认定为两直线的最短距离。

**C19-12**
**答案：** 可取

$$x=2\cos t,\qquad y=4\sin^2t,\qquad z=2\sin t,\qquad 0\le t<2\pi.$$

投影曲线为 $y=4-x^2$、$-2\le x\le2$、$z=0$。在两个端点 $(\pm2,0,0)$ 处各对应原曲线的一个点，其余投影点各对应两个点。

因为 $(x,z)$ 遍历整个圆 $x^2+z^2=4$，而 $y=z^2$ 唯一确定，所以上述参数式既满足两个方程，也覆盖整条交线。

消去原曲线的 $z$，得到投影柱面 $x^2+y=4$。但原曲线还要求 $z^2=y\ge0$，所以必须有 $-2\le x\le2$。反过来，在这个范围内取原高度 $z=\pm\sqrt{4-x^2}$ 就能回到原曲线，所以没有漏点。投影点的高度另设为 0。

当 $x=\pm2$ 时，两个平方根同为 0；当 $-2<x<2$ 时，一正一负给出两个不同高度。因此只写整条抛物线会加入无法找到实数原高度的点。

区分点：消元得到的方程通常只是必要条件，须检验实数原像是否存在，并区分原高度与投影后的高度。

### 章末混合练习

**C19-13**
**答案：** $t>0$ 时是球心 $(t,0,0)$、半径 $\sqrt{2t}$ 的球面；$t=0$ 时是原点；$t<0$ 时是空集。在给定参数区间内，最小 $x$ 为 $-1/2$，在 $t=1/2$、点 $(-1/2,0,0)$ 处取到。（本章方法 11；C.8 方法 4。）

配方得 $(x-t)^2+y^2+z^2=2t$，由右边的正负得到分类。固定 $t\ge0$ 时，最左端点的横坐标是 $f(t)=t-\sqrt{2t}$，并且确能在 $y=z=0$ 时取到。

对 $t>0$，$f'(t)=1-1/\sqrt{2t}$，唯一驻点是 $t=1/2$。比较 $f(0)=0$、$f(1/2)=-1/2$、$f(2)=0$，得到所求最小值。

区分点：先确认参数对应的点集存在，再把每个球面的最左端点转成一个函数，不能只比较球心。

**C19-14**
**答案：** 投影区域为 $D=\{(x,y)\mid(x-1)^2+y^2\le1\}$，面积为 $\pi$。（本章方法 15；C.13 方法 2。）

给定 $(x,y)$ 后，存在满足要求的 $z$，当且仅当下界不超过上界，即 $x^2+y^2\le2x$。配方得所述圆盘；等号是边界，不能只保留等号。

当 $0\le x\le2$ 时，纵向线段的上下端为 $y=\pm\sqrt{1-(x-1)^2}$，所以面积为

$$S=\int_0^2 2\sqrt{1-(x-1)^2}\,\mathrm{d}x=\int_{-\pi/2}^{\pi/2}2\cos^2\theta\,\mathrm{d}\theta=\pi.$$

换元用了 $x-1=\sin\theta$，并在该区间内用 $\cos\theta\ge0$ 化简根号。

区分点：投影区域由原高度存在的条件确定，面积积分再取每条竖直线段的完整长度。

**C19-15**
**答案：** 最小距离为 1，在 $t=0,1$ 时取到；最大距离为 $\sqrt{66}/8$，在 $t=1/2$ 时取到。（本章方法 10；C.8 方法 4。）

取直线上一点 $M=(0,0,1)$、方向 $\boldsymbol{s}=(1,1,0)$，有

$$\overrightarrow{MP}\times\boldsymbol{s}=(1,-1,t-t^2),\qquad d(t)^2=1+\frac{(t-t^2)^2}{2}.$$

平方根递增，所以只须比较 $F(t)=d(t)^2$。其导数为 $F'(t)=(t-t^2)(1-2t)$，区间内部唯一驻点为 $1/2$。比较两端和驻点，得 $F(0)=F(1)=1$、$F(1/2)=33/32$，再开平方得到答案。

区分点：先用空间距离构造单变量函数，再比较闭区间端点与驻点；只找垂足还没有解决运动点的最值问题。
