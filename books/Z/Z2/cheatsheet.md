## Z.2 · 推得出与推不出：推理规则与推理链（速记）

| 提示 | 内容 |
|---|---|
| 有效 | 前提全真时结论不可能为假；只看形式，不管前提实际真不真 |
| 方法 1：找反例 | 找「前提全为 1、结论为 0」的行；找到即无效。字母多时反推：设结论为 0、前提为 1，推出矛盾即有效；没有字母被迫取值时分情况 |
| 肯定前件式 | $p\to q$，$p$，推出 $q$ |
| 否定后件式 | $p\to q$，$\neg q$，推出 $\neg p$（逆否命题 + 肯定前件） |
| 两个谬误 | 否定前件（由 $\neg p$ 推 $\neg q$）、肯定后件（由 $q$ 推 $p$）都无效；口诀：肯前必肯后，否后必否前，否前、肯后推不出 |
| 方法 2 | 先把「只有、除非」译成 $X\to Y$，再看事实落在前件还是后件 |
| 相容的或 | $p\vee q$，$\neg p$，推出 $q$；肯定一支推不出另一支的否定（反例：两支都真） |
| 不相容的或 | $p\oplus q$：否定一支就肯定另一支，肯定一支就否定另一支 |
| 假言连锁 | $p\to q$，$q\to r$，推出 $p\to r$ |
| 方法 4：箭头图 | 每条规则连同逆否箭头一起画；「或」改写成 $\neg p\to q$、$\neg q\to p$；从事实出发顺着箭头走，走到的都推得出；走不到时构造反例，构造不出来（如 $p\to r$、$\neg p\to r$）说明要分情况 |
| 二难推理 | $p\to r$，$q\to r$，$p\vee q$，推出 $r$；常用 $p\vee\neg p$ 分情况；各支必须覆盖全部情况 |
| 归谬 | 由 $p$ 推出矛盾，得 $\neg p$；特例 $p\to\neg p\equiv\neg p$；要证 $p$ 就从 $\neg p$ 推矛盾（反证法） |
| 四种问法 | 在可行情形里：全为 1 一定为真；有 1 可能为真；全为 0 一定为假；有 0 不能推出 |
| 互为否定的问法 | 「一定为真」↔「不能推出」；「一定为假」↔「可能为真」 |
| 易错 | 「只有 $A$ 才 $B$；$A$」推不出 $B$；「除非 $A$ 否则 $B$；$A$」推不出 $\neg B$；肯定相容或的一支推不出另一支不成立 |
