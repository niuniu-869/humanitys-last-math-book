## Z.5 · 计数：排列组合、容斥与鸽巢（速记）

| 提示 | 内容 |
|---|---|
| 方法 1 加法与乘法原理 | 分类：类不重不漏，相加；分步：每一步的选法个数不随前面变，相乘；受限位置先排，限制互相牵扯时先分类 |
| 排列与组合 | $\mathrm{A}_n^k=n(n-1)\cdots(n-k+1)=\frac{n!}{(n-k)!}$；$\mathrm{C}_n^k=\frac{\mathrm{A}_n^k}{k!}=\frac{n!}{k!(n-k)!}$；$0!=1$，$\mathrm{C}_n^k=\mathrm{C}_n^{n-k}$；交换两个被选对象结果不变就是组合 |
| 数重几遍就除以几 | 先按有顺序数，再除以每个结果的重复遍数；只有遍数都相同时才能除（定序：$n$ 人中甲在乙左，$n!\div2$） |
| 「至少一个」 | 总数减「一个也没有」；「先选一个保证条件，再任选」会数重，而且重的遍数不齐 |
| 方法 3 捆绑与插空 | 相邻：捆成一个对象，乘捆内排法；不相邻：先排其余 $m$ 个，留出 $m+1$ 个空位，插进不同空位；两种要求同时有时先捆后插 |
| 方法 4 分组与分配 | 有名字的组：$\frac{n!}{n_1!\cdots n_k!}$；$r$ 个大小相同的无名堆再除以 $r!$；「每人至少一个」：列出大小 → 分堆 → 乘 $k!$ |
| 方法 5 隔板 | $x_1+\cdots+x_k=n$：正整数解 $\mathrm{C}_{n-1}^{k-1}$，非负整数解 $\mathrm{C}_{n+k-1}^{k-1}$（每人先借一个）；有下限先换元 |
| 相同还是不同 | $n$ 个不同东西给 $k$ 人可空：$k^n$；$n$ 个相同东西：隔板。不同东西不能用隔板 |
| 格路 | 从 $(0,0)$ 只向右、向上到 $(m,n)$：$\mathrm{C}_{m+n}^{m}$；经过某点：两段路线数相乘 |
| 方法 6 双计数与二项式 | $\mathrm{C}_n^k=\mathrm{C}_{n-1}^{k-1}+\mathrm{C}_{n-1}^{k}$；$(a+b)^n=\sum_{k=0}^n\mathrm{C}_n^ka^{n-k}b^k$，通项是第 $k+1$ 项，符号和系数并进 $a,b$ 一起乘方 |
| 二项式系数的和 | $\sum_{k=0}^n\mathrm{C}_n^k=2^n$；$\sum_{k=0}^n(-1)^k\mathrm{C}_n^k=0$（$n\ge1$）；$\sum_{k=1}^nk\,\mathrm{C}_n^k=n2^{n-1}$ |
| 方法 7 容斥 | $\lvert A\cup B\cup C\rvert=\sum\lvert A\rvert-\sum\lvert A\cap B\rvert+\lvert A\cap B\cap C\rvert$；「都不」= 总数 − 并集；1 到 $N$ 中 $d$ 的倍数有 $\lfloor N/d\rfloor$ 个 |
| 不空与错排 | $n$ 个不同东西给 $k$ 人每人至少一个：$k^n-\mathrm{C}_k^1(k-1)^n+\mathrm{C}_k^2(k-2)^n-\cdots$；$D_n=n!\sum_{j=0}^n\frac{(-1)^j}{j!}$，$D_3=2,\ D_4=9,\ D_5=44$ |
| 方法 8 鸽巢 | $N$ 个放进 $n$ 盒，必有一盒至少 $\lceil N/n\rceil$ 个；先按要找的关系造盒子 |
| 「至少几个才能保证」 | 答案 = 最坏情形的个数 + 1；既要证这么多够，也要举出少一个时不够的例子 |
