## Z.4 · 证明：把推理写成文字（速记）

| 提示 | 内容 |
|---|---|
| 奇偶、整除的定义 | $n$ 偶 ⇔ 存在整数 $k$ 使 $n=2k$；$n$ 奇 ⇔ 存在整数 $k$ 使 $n=2k+1$；$a\ne0$ 时，$a\mid b$ ⇔ 存在整数 $m$ 使 $b=am$ |
| 方法 1 直接证明 | 任取满足前件的对象 → 按定义拆成等式 → 先写出目标的形状 → 推到目标、装回定义；两个对象用两个不同的字母 |
| 推理方向 | 举例不是证明；从结论推出一个真式子也不是证明，纸上要从前件往结论正着写 |
| 方法 2 逆否证明 | 证 $\neg Q\to\neg P$；条件落在不好用的一侧时用（如「$n^2$ 偶 ⇒ $n$ 偶」） |
| 方法 3 反证法四步 | 写出结论的否定 → 当作已知往下推 → 推出矛盾 → 原结论成立；信号：不是、不存在、无穷多、至多 |
| 逆否 vs 反证 | 逆否只用 $\neg Q$，目标是指定的 $\neg P$；反证用题设（若有）和 $\neg Q$，目标是任何一个矛盾 |
| 方法 4 构造与反例 | 证「存在」：造出来再验证（对方先选 $n$ 时用 $n$ 写公式）；推翻 $\forall x(P\to Q)$：找 $P$ 真、$Q$ 假的 $x$，前件也要验证 |
| 例子与反例 | 一个例子能证「存在」、证不了「所有」；一个反例能推翻「所有」、推翻不了「存在」 |
| 方法 5 分情况 | 只用一个分类标准，合起来覆盖全体，分界点归进某一段；不漏是必须的，不重是为了省事；对称时才能「不妨设」 |
| 归纳法为什么不是循环论证 | 归纳步证的是「如果 $P(m)$ 那么 $P(m+1)$」，证一句「如果」只需假设前件；$P(m)$ 真不真由奠基加前面的链环决定 |
| 方法 6 数学归纳法 | 奠基 $P(n_0)$；任取 $m\ge n_0$，假设 $P(m)$，推出 $P(m+1)$，指出用假设的那一步；两者缺一不可 |
| 方法 7 求和号变形 | 拆末项 $\sum_{k=1}^{n+1}a_k=\sum_{k=1}^na_k+a_{n+1}$；$\sum(ca_k+b_k)=c\sum a_k+\sum b_k$，$\sum_{k=1}^n1=n$；换下标 $j=k+1$ 时上下限一起换 |
| 常用和 | $\sum_{k=1}^nk=\frac{n(n+1)}2$，$\sum_{k=1}^nk^2=\frac{n(n+1)(2n+1)}6$，$\sum_{k=1}^n(2k-1)=n^2$，$\sum_{k=1}^n\frac1{k(k+1)}=1-\frac1{n+1}$ |
| 方法 8 强归纳 | 假设 $P(n_0),\dots,P(m)$ 都成立；递推用到前几项就奠基几项；与最小反例原理是同一个论证 |
| 方法 9 加强归纳假设 | 假设没有余量时证更强的界，如 $\sum_{k=1}^n\frac1{k^2}\le2-\frac1n$ |
| 高频易错 | 归纳字母和求和下标同名；把 $P(m+1)$ 当已知；起点选错或只奠基一项；反证时否定式写错 |
