## Z.3 · 「所有」与「有的」：从直言命题到量词（速记）

| 提示 | 内容 |
|---|---|
| 四种直言命题 | A 所有 S 是 P；E 所有 S 不是 P；I 有的 S 是 P；O 有的 S 不是 P。「有的」= 至少一个，不暗示「不是全部」 |
| 维恩图 | ① S 里 P 外，② S、P 共有。A：① 空；E：② 空；I：② 有对象；O：① 有对象。阴影 = 空，× = 至少一个 |
| 易混说法 | 「所有 S 都不是 P」是 E；「并非所有 S 都是 P」「S 不都是 P」是 O；「只有 P 才是 S」= 所有 S 是 P |
| 对当关系 | A–O、E–I 矛盾（恰一真）；A–E 反对（不能同真）；I–O 下反对（不能同假）；A→I、E→O 从属。反对、下反对、从属要 S 非空 |
| 方法 2 | 在 S 非空的前提下，全称真、特称假：四句全定；全称假、特称真：只定它的矛盾句 |
| 换位、换质 | E、I 可直接换位；A 不能直接换位；若 S 非空，则可推出「有的 P 是 S」；O 不能换位。换质：所有 S 是 P ≡ 没有 S 是非 P；A ≡ 所有非 P 是非 S |
| 方法 3 | 「有的」请出一个带两个标签的对象，顺着「所有」的箭头走；两个「有的」接不上；不能逆着箭头走 |
| 三段论检验 | 三个圆分成 8 块，编号 $(s,p,m)$；先涂全称前提的阴影，再画特称的 ×；× 可落两块时压线；结论已在图上才有效 |
| 符号化 | 全称配蕴含：$\forall x\,(S(x)\to P(x))$；存在配合取：$\exists x\,(S(x)\wedge P(x))$；先定论域 |
| 真空为真 | S 为空时 $\forall x\,(S(x)\to P(x))$ 为真（空集是任何集合的子集）；没人选音乐课时「选音乐的都选了数学」与「选音乐的都没选数学」同真 |
| 量词的否定 | $\neg\forall x\,P(x)\equiv\exists x\,\neg P(x)$，$\neg\exists x\,P(x)\equiv\forall x\,\neg P(x)$；里面的 $\to$ 否定成「且非」；常见错误：把 $\neg\forall$ 写成 $\forall\neg$ |
| 出招 | 从左往右：$\exists$ 你选，$\forall$ 对方选；你的选择写成对方先选值的公式 |
| 量词次序 | $\exists y\,\forall x$ 推出 $\forall x\,\exists y$，反之不行；同类量词可交换；有上界 $\exists M\,\forall x\,f(x)\le M$，无上界 $\forall M\,\exists x\,f(x)>M$ |
| 模态 | 必然 = 所有可能情况，可能 = 有的可能情况；不一定 $p$ = 可能非 $p$；不可能 $p$ = 必然非 $p$ |
