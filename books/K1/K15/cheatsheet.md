## K1.5 · 论证题与判断题：削弱、加强、假设、解释、评价（速记）

| 提示 | 内容 |
|---|---|
| 论证三件 | 论点（要人信的话）、论据（拿出的事实）、桥（没说出口、让论据通向论点的那句话）。五种论证题问的都是桥；结论、相似、统计、概念、定义五种看翻译与推理 |
| 桥的五种样子 | 因果桥（没有他因、方向没反）、样本桥（样本有代表性）、类比桥（关键处相似）、概念桥（论据与论点说的是一回事）、方案桥（代价可接受、没有更好办法） |
| 方法 1 | 找论点（所以、因此、可见）→ 找论据（因为、数据显示）→ 划掉背景和被反驳的观点 → 补桥 |
| 削弱 | 攻论点（反例）、攻论据（不可靠、口径变了）、攻桥身（他因、倒置、共同原因、换概念）；无关项和方向反的都不算 |
| 加强 | 搭桥、排除他因（对照最强）、补论据（共变、论据可靠）、举正面例子；只描述现象、没触动桥的不算 |
| 力度比较 | 似然比 $L=P(E\mid H)/P(E\mid\neg H)$ 看 $|\ln L|$：$L=2$ 与 $L=0.5$ 同力度、方向相反；条件相近时，直接对着论点或桥 > 质疑论据；确有 > 可能；范围大 > 范围小 |
| 必须假设与取非法 | 把选项取非放进论证：论证塌 = 必须假设；变弱 = 加强项；说得太绝对（所有、唯一、最大）的通常不是。充分假设补上就必然推出，通常很强；必须假设去掉就塌，通常较弱。问「依赖」找必要，问「补上什么能使成立」找充分 |
| 解释 | 写出两个事实及看似矛盾的原因，找第三个量：总量 = 个数 × 平均、比例的分母变了、对象或口径不同；只解释一个的不选 |
| 评价 | 对问句设想「是」和「否」两种回答，让论证朝相反方向变的最好；两个回答都不改变论证的无关 |
| 结论题 | 找不到反例才算一定为真；错误选项：范围放大、逆命题或否命题、相关升级为因果、无中生有、绝对化 |
| 相似推理 | 去内容换字母，比较前提个数、联结词、推理方向（肯前、否后、肯后、否前）、否定位置；有效对有效，无效对无效 |
| 数字四问 | 比例还是绝对数、分母是谁？平均数有无极端值？合并数据有无分组变量？对象经过什么筛选？百分点 $\ne$ 百分比 |
| 概念关系 | 全同、种属、交叉、矛盾（全异且合起来是全体）、反对（全异但还有第三种）；先试举一个公共成员 |
| 定义判断 | 拆成要件（主体、条件、行为、结果），每个选项逐条打勾；先看联结词：「并且」缺一不可，「或」满足一个即可 |
| 限时混合 | 先读最后一句问法判题型，再读题干找这类题要的东西，一道一两分钟，超时做记号 |
