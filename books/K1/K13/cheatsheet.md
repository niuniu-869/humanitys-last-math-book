## K1.3 · 排兵布阵：分析推理（速记）

| 提示 | 内容 |
|---|---|
| 匹配表 | 行是人，列是属性；每行每列恰有一个 ✓（要求一人一属性、一属性一人）；填一个 ✓，同行同列其余填 ✗；某行（列）只剩一格就是 ✓ |
| 方法 1：匹配表 | 先填直接给出的「是」「不是」，再反复用「每行每列恰一个勾」推；推不动时用其余条件，仍不行就对候选分支检查 |
| 属性合并 | 条件把两类属性绑在一起（北京＝医生）时，先合并成一类，只画一张表 |
| 条件的信息量 | 四人 24 种排法中：固定位置或固定方向的紧挨保留 6 种；相邻、在某人前面各保留 12 种；不在指定位置保留 18 种；加入已有条件后须重新比较 |
| 方法 2：最大信息优先 | 数每条未用条件在当前剩余排法里留下几种，留得最少的先用；用完重数，因为强弱随剩余而变（已绑成块后「甲在乙前」不再排除）；相邻的人绑成块 |
| 方法 3：选项代入 | 条件先翻译好；选最容易检验的条件把选项过一遍，违反一条就出局，不再看其余条件 |
| 条件句的前件 | 「如果 $p$ 则 $q$」在 $p$ 不成立时对这一套安排没有要求；「只有 $q$ 才 $p$」＝ $p\to q$；「除非 $q$，否则不 $p$」＝ $p\to q$ |
| 选项代入与先解后选 | 选项是完整安排、条件易检验时用代入；条件强到能推出唯一安排、选项只问一部分时先解 |
| 方法 4：先算数量 | 先写容量；「同组」的几个人若恰好占满一个组，其余人不能进；某组空位少于要进的人数就排除 |
| 容量与否定条件 | 用「放进去会超员」来排除「某人在某组」，比逐个试更快 |
| 方法 5：可行安排表 | 用树状分支列全所有可行安排；附加条件只保留满足它的安排；再逐项检查 |
| 一定与可能 | 一定为真＝每个可行安排都成立；可能为真＝至少一个成立；一定为假＝没有一个成立；不一定为真＝至少一个不成立 |
| 易错 | 只找到一种安排就说「一定」；把「不一定为真」当成「一定为假」；把「如果……那么……」读成「必须发生」 |
