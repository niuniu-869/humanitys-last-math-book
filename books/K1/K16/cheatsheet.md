## K1.6 · 机器怎么推理：规则、求解器与大模型（速记）

| 提示 | 内容 |
|---|---|
| 两条路线 | 符号推理：人写规则，每步有依据，规则对则必对，覆盖窄；统计推理（大模型）：从数据学，覆盖宽，每步只是可能对，没有保证 |
| SAT | 给一串子句（合取范式），问有没有一组真假取值使全部为真；输出一组取值或「不可满足」 |
| 把约束写成子句 | 「$x$ 与 $y$ 不同」= $(x\vee y)\wedge(\neg x\vee\neg y)$；「$x$ 与 $y$ 相同」= $(\neg x\vee y)\wedge(x\vee\neg y)$；已知事实 = 单位子句 |
| 单位传播 | 子句只剩一个文字时必须取它；代入后真的子句划掉，假的文字删掉 |
| 方法 1：DPLL | 传播 → 没有单位子句就决定一个变量 → 子句被删空即冲突，回溯换值 → 全真得解，两个值都冲突则不可满足 |
| 最坏情形 | $n$ 个变量有 $2^n$ 种取值，SAT 是第一个 NP 完全问题；实际靠传播剪枝和冲突后学习新子句，能处理百万变量 |
| 验证比求解便宜 | 给定一组取值，逐个子句核对即可；不可满足也可以给出归结证明供检查 |
| 霍恩规则 | $A\wedge B\to C$，只含「并且」和「推出」；用于规则引擎 |
| 方法 2：前向链 | 反复触发前提都已知的规则，直到没有新事实；适合事实陆续到来、要全部结论；用计数器时耗时与规则库大小成正比 |
| 方法 3：后向链 | 从目标出发，找结论是目标的规则，把前提当新目标，问到事实则成立，问到既非事实又无规则则失败；适合只问一个问题 |
| 封闭世界假设 | 没推出就当作不成立；本章的规则只能推出正事实，不能推出否定结论；要处理冲突需要优先级 |
| 链长连乘 | 每步正确率 $\alpha$，$n$ 步全对 $\alpha^n$：$0.95^{20}\approx0.358$ |
| 方法 4：投票 | $k$ 条链各自答对概率 $q$，多数票答对 = $B(k,q)$ 超过一半；公式假设只有两个候选、各链独立、$q>0.5$；候选多于两个时公式只是保守估计；$q<0.5$ 越投越错，链完全相关则不提高 |
| 检查器 | 求解器、证明检查器能确定地判对错（前提是检查器和形式化本身没错）；测试只能发现错误，不能保证没有错误；生成 $k$ 个、至少一个对的概率 $1-(1-q)^k$ |
| 翻译仍会错 | 检查器只核对形式化以后的东西，翻译出错时它会可靠地解出一个错的问题 |
