## K1.4 · 证据怎样支持结论：归纳、因果与概率（速记）

| 提示 | 内容 |
|---|---|
| 演绎与归纳 | 演绎：前提全真则结论一定为真，评价用有效或无效；归纳：结论说得比前提多，前提全真也可能为假，评价用强或弱 |
| 归纳强弱三要素 | 样本量、样本的代表性（随机抽样优先）、结论说得多满；有偏的大样本不如随机的小样本 |
| 不完全归纳 | $n^2+n+41$ 对 $n=0,\dots,39$ 都是素数，$n=40$ 时为 $41^2$；有限个例子不能证明一般结论 |
| 数学归纳法 | 属于演绎：第二步证明了对每个 $k$，由 $k$ 成立推出 $k+1$ 成立 |
| 论证结构图 | 前提 → 隐含假设 → 结论；先找出缺口处的假设 |
| 求同法与求异法 | 求同：结果出现的场合共有的先行情况；求异：结果不同的两个场合只差一个先行情况；并用：正面场合共有、反面场合都没有 |
| 对照与随机分组 | 求异法要求其他条件相同；随机分组把共同原因平均分给两组；A/B 城的差扣掉共同因素才是处理的作用 |
| 共变法与剩余法 | 共变：一个量变化时另一个量跟着变，只说「可能」有因果；剩余：总量减去已解释的部分，剩下的归于其余原因 |
| 相关的五种解释 | A 导致 B；B 导致 A（因果倒置）；共同原因 C；选择偏差；巧合 |
| 方法 2 的四问 | 反过来行不行？有没有共同原因？样本怎么选的？是不是巧合？ |
| 辛普森悖论 | 每个分组里 A 都更好，合并后 B 更好：病情这类共同原因影响了分组的人数 |
| 赔率与似然比 | 赔率 $o=p/(1-p)$，$p=o/(1+o)$；$LR=P(E\mid H)/P(E\mid\neg H)$，$LR>1$ 支持，$=1$ 无关，$<1$ 反对 |
| 赔率形式的贝叶斯 | 后验赔率＝先验赔率×$LR$；多条证据要在 $H$、$\neg H$ 下各自独立才能连乘，同一条证据不能算两次；先验为 0 则永远为 0 |
| 忽视基础率 | 同一个 $LR=10$，先验赔率 $1:99$ 时后验约 9.2%，先验 $1:4$ 时约 71.4% |
| 常见谬误 | 以偏概全（缺代表性）、诉诸权威（缺专长与论据）、滑坡（每步概率连乘）、偷换概念（词义不一致）、循环论证（前提预设结论） |
