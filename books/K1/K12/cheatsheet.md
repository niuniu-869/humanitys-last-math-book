## K1.2 · 谁说了真话：真假推理（速记）

| 提示 | 内容 |
|---|---|
| 真话个数 | 真话记 1、假话记 0；「恰有 $k$ 句真话」就是这一行的合计等于 $k$，「至少」「至多」换成 $\ge$、$\le$ |
| 含「且」的一句话 | 每个部分都对才算真；含「或」的话，一个部分对就算真 |
| 方法 1：枚举表 | 列全所有情况；每句话一列；逐行填 1/0；留下合计等于题目所给数字的行 |
| 矛盾对 | 在任何情况下必然一真一假的两句；常见形式：$S$ 与 $\neg S$，「所有 $A$ 是 $B$」与「有的 $A$ 不是 $B$」，$p\to q$ 与 $p\wedge\neg q$，$p\vee q$ 与 $\neg p\wedge\neg q$ |
| 矛盾对占去的真话 | $n$ 句话恰 $k$ 句真，矛盾对占 1，其余 $n-2$ 句里恰 $k-1$ 句真；$k=1$ 时其余全假 |
| 方法 2：先找矛盾对 | 找对、验证对、减去它、定其余、回代 |
| 反对 / 下反对 | 反对：不能同真、可以同假（至多一真）；下反对：不能同假、可以同真（至少一真）；矛盾：既不能同真也不能同假 |
| 易错 | 「甲是第一」与「乙是第一」是反对，不是矛盾对 |
| 方法 3：假设法 | 问每句话「它为真时能定下几句别的话」，从定下最多的一句假设；推到矛盾就排除，没矛盾要回代并查另一个分支 |
| 骑士与无赖 | $k_A\leftrightarrow S$：$A$ 是骑士当且仅当他说的话为真；每人只说一句时，骑士人数等于真话个数 |
| 同类 / 异类 | 说「他是骑士」的人与他同类；说「他是无赖」的人与他异类；没有人能说「我是无赖」 |
| 方法 5：被提到最多的断言 | 每人两句、恰一真一假：数每个断言被提到的次数，先对次数最多的断言作假设，一次定下好几个人的另一条 |
| 回代 | 每道题最后用求出的事实把所有话再算一遍，核对真话数 |
