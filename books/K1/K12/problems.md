### A 基础

**K12-01**〔A｜方法 1 · 考查：枚举并正确处理“或”〕整数 $x$ 取 $1,2,3,4$ 之一。四个命题依次为 $x=1$、$x=2$、“$x=1$ 或 $x=2$”、“$x=1$ 或 $x=3$”。已知恰有两个命题为真，求 $x$。

**K12-02**〔A｜方法 2 · 考查：识别互为矛盾的两句话〕四个数 $a,b,c,d$ 中恰有一个是 1，其余是 0。甲：$a=1$。乙：$a=0$。丙：$b=1$。丁：$c=1$。已知恰有两句话为真。问哪些数可以确定？

**K12-03**〔A｜方法 4 · 考查：把“说他是骑士”翻成同类关系〕岛上有甲、乙、丙三人，每人只可能是骑士或无赖，骑士只说真话，无赖只说假话。甲说：“乙是骑士。”乙说：“丙是无赖。”丙说：“甲和乙是同类。”判断三人的身份。

**K12-05**〔A｜方法 3 · 考查：反对关系与部分确定信息〕整数 $x$ 取 $0,1,2,3,4$ 之一。三个命题依次为 $x<2$、$x>2$、$x\ne2$，其中恰有两个为真。下列哪项一定成立？

(A) $x<2$ 　(B) $x>2$ 　(C) $x\ne2$ 　(D) $x=0$

**K12-10**〔A｜方法 1 · 考查：逐项对应的计数证明〕有 $n$ 个命题，每个命题对应一个数 $t_i$，下标 $i=1,2,\ldots,n$ 是命题的编号。第 $i$ 个命题为真时 $t_i=1$，为假时 $t_i=0$。证明：$t_1+\cdots+t_n$ 等于这些命题中真命题的个数。

### B 进阶

**K12-04**〔B｜方法 5 · 考查：沿重复断言传递真假〕$a,b,c,d$ 分别取 $1,2,3,4$，且互不相同。下面四对命题中，每对恰好一真一假，求 $(a,b,c,d)$。

1. $b=1$ 与 $c=3$；
2. $b=1$ 与 $d=4$；
3. $a=2$ 与 $d=4$；
4. $a=2$ 与 $c=1$。

**K12-06**〔B｜方法 1 · 考查：循环条件句的真命题个数〕$p,q,r$ 均为真假命题。考虑“如果 $p$，那么 $q$”“如果 $q$，那么 $r$”“如果 $r$，那么 $p$”三个命题。下列哪个数可能是它们中真命题的个数？

(A) $0$ 　(B) $1$ 　(C) $2$ 　(D) $4$

**K12-07**〔B｜方法 3 · 考查：用真命题个数限制分支〕$a,b,c,d$ 分别取 $1,2,3,4$，且互不相同。下面五个命题中恰有两个为真，求 $(a,b,c,d)$。

1. $a\ne1$；
2. $d\ne1$；
3. $c<b$；
4. $c\ne1$；
5. $d<c$。

**K12-08**〔B｜方法 4 · 考查：数量条件与真值的对应〕$a,b,c,d$ 各取 $0$ 或 $1$，令 $k=a+b+c+d$。它们满足下面四个条件，求 $(a,b,c,d)$。

1. $a=1$ 当且仅当 $k=2$；
2. $b=1$ 当且仅当 $k=1$；
3. $c=1$ 当且仅当 $k=3$；
4. $d=1$ 当且仅当 $a=b$。

**K12-09**〔B｜方法 3 · 考查：看起来有矛盾对，实际只是反对关系〕$a,b,c,d$ 分别取 $1,2,3,4$，且互不相同。四个命题 $a=1$、$b=1$、$c\ne4$、$d\ne4$ 中恰有一个为真。下列说法正确的是（ ）。

(A) 一定有 $a=1$ 　(B) 一定有 $b=1$ 　(C) 一定有 $c\ne4$ 　(D) 这些条件不能唯一确定四个数

### 混合练习

**K12-11**〔B〕$p,q,r$ 均为真假命题。已知下面四句话中恰有两句为真：

1. 如果 $p$，那么 $q$；
2. $p$ 且非 $q$；
3. $q$ 或 $r$；
4. 非 $r$。

求所有可能的 $(p,q,r)$。

**K12-12**〔B〕$a,b,c,d$ 分别取 $1,2,3,4$，且互不相同。下面三对命题中，每对恰好一真一假：

1. $b=1$ 与 $b=4$；
2. $b=1$ 与 $d=4$；
3. $b=1$ 与 $a=1$。

先求全部可能的 $(a,b,c,d)$，再判断单独补充下列哪一项能得到唯一解，并写出这个唯一解。

(A) $a<c$ 　(B) $d<c$ 　(C) $a>c$ 　(D) $c=3$

**K12-13**〔C〕岛上有甲、乙、丙、丁四人，每人只可能是骑士或无赖。每人只说一句，骑士说真话、无赖说假话：甲说“乙是骑士且丙是无赖”；乙说“甲和丁同类”；丙说“岛上恰有两个无赖”；丁说“乙是骑士”。求所有人的身份，并说明为什么不能只把每句话看成“同类”或“异类”的连线。

拆法：先做 K12-03、K12-08。

**K12-14**〔C〕$a,b,c,d$ 分别取 $1,2,3,4$，且互不相同。下面五个命题中恰有两个为真：

1. 如果 $a=4$，那么 $b<a$；
2. 如果 $c=1$，那么 $d<a$；
3. $d=4$；
4. $c<a$；
5. $a<c$。

求 $(a,b,c,d)$，并把第 1、2 句先翻译成命题逻辑式再计算。

拆法：先做 K12-07、K12-11。
