## M.14 · 生成与采样：温度、top-k、top-p（速记）

| 提示 | 内容 |
|---|---|
| 生成循环 | 算分布 $p_\theta(\cdot\mid x_{<t})$ → 选一个词接在后面 → 重复，直到结束符或长度上限；本章只改「选」这一步 |
| 贪心 | $x_t=\arg\max p_i$；每次一样，容易绕圈（相当于沿马尔可夫链概率最大的箭头走） |
| 累积概率抽样 | $c_i=p_1+\cdots+p_i$；$u\sim U[0,1)$（$[0,1)$ 上均匀），取第一个 $c_i>u$ 的 $i$；$P(\text{选 }i)=c_i-c_{i-1}=p_i$（离散的逆变换） |
| 温度 | $p_i(T)=e^{z_i/T}/\sum_je^{z_j/T}$；$p_i/p_j=e^{(z_i-z_j)/T}$；$T<1$ 集中、$T>1$ 平；等价于概率开 $1/T$ 次方再归一化 |
| 熵随温度 | $\mathrm dH/\mathrm d\beta=-\beta\,\mathrm{Var}(z)\le0$（$\beta=1/T$），所以 $H$ 随 $T$ 增大不减，上限 $\ln V$（$V$ 为词表大小） |
| 老朋友④的熵 | $T=0.5,1,2$ 时 $H\approx0.441,\ 0.832,\ 1.020$（奈特），$\ln3\approx1.0986$ |
| top-$k$ | 保留概率最大的 $k$ 个，除以它们的概率之和；设其余打分为 $-\infty$ 等价；$k=1$ 是贪心；不看分布形状 |
| top-$p$（核采样） | 从大到小累积，取最小的 $m$ 使 $c_m\ge p$，核内重新归一化；分布尖则核小、分布平则核大 |
| 老朋友④的核 | $p=0.9$：核是前两个词，$(0.7311,\ 0.2689)$ |
| 流水线顺序 | 除以温度 → top-$k$ → softmax → top-$p$ → 抽样；先温度再 top-$p$（温度会改变累积概率） |
| 束搜索 | 每步保留对数概率之和最高的 $B$ 条候选；整句最优不等于每步最优 |
| KV 缓存 | 因果掩码使旧位置的 $K,V$ 不变；每步只算新词元；无缓存生成 $n$ 个词元共处理 $n(n+1)/2$ 次，有缓存 $n$ 次；每词元占 $2\times L\times d\times$ 字节数 |
| 易错 | 截断后忘记重新归一化；把 top-$p$ 当成「概率之和等于 $p$」（是不少于 $p$ 的最小集合）；先 top-$p$ 再温度 |
