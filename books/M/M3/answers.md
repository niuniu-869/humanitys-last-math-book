## M.3 · 泛化：过拟合、偏差–方差、交叉验证与正则化（答案）

### A 基础

**M3-01**
**答案：** 选 (B)。甲、乙、丙的交叉验证误差依次为 $2,5/3,3$，所以乙最小。

(A) 只取了甲的第一折，忽略了其余两折。(C) 把丙的训练误差当成验证误差。(D) 每折分别挑最小值，拼出了不属于任何一个固定候选的结果；第三折的 $1$ 来自甲或乙。

区分点：必须沿同一候选的整行求平均，不能跨候选拼接。

**M3-02**
**答案：** $E\hat f=3/2$，偏差的平方为 $9/4$，方差为 $1$，期望平方误差为 $17/4$。

令导数 $2w-Z=0$，得 $\hat f=Z/2$。因为 $EZ=3$、$\mathrm{Var}(Z)=4$，所以均值减半、方差变为原来的 $1/4$。新标签噪声方差为 $1$，于是总误差为 $1+(3-3/2)^2+1=17/4$。

区分点：缩小预测值同时改变均值和方差，不能只算方差下降而漏掉偏差。

**M3-03**
**答案：** 选 (C)。这里 $z=-2,\lambda=2$，因为 $|z|=\lambda$，所以最小值点为 $0$。

(A) 把阈值误用成 $\lambda/2=1$。(B) 套用了 L2 的比例收缩。(D) 沿远离零的方向移动了 $2$。在 $w<0$ 时 $g'(w)=w<0$，在 $w>0$ 时 $g'(w)=w+4>0$，所以 (C) 是唯一最小值点。

区分点：软阈值的等号情形仍取零，不能在尖角处直接令普通导数为零。

**M3-04**
**答案：** 原来 $w=5/3,b=3$；平移后 $w=5/3,b=7$。

因为 $\bar x=0,\bar y=3$，所以 $S_{xx}=2,S_{xy}=5$，得到 $w=5/(2+1)=5/3$，$b=\bar y-w\bar x=3$。所有标签加 $4$ 后，去均值的标签不变，故斜率不变，偏置加 $4$。

区分点：平移标签改变的是不受惩罚的偏置；若连偏置一起罚，便不能这样推断。

**M3-05**
**答案：** 选 (C)，AUC 为 $7/8$。共有 $4$ 对，分数 $3$ 的正例胜 $2$ 对，分数 $1$ 的正例胜 $1$ 对并列 $1$ 对，所以 AUC 为 $(2+1+1/2)/4=7/8$。

(A) 漏掉了并列的半对。(B) 把并列算成全胜。(D) 的 $2/3$ 是阈值 $1$ 下的精确率：判正的三个样本中有两个正例，不能拿它代替 AUC。

区分点：AUC 的分母是正负配对数，并列得分只贡献半对。

### B 进阶

**M3-06**
**答案：** $\sigma^2=4,p=8$；样本数为 $80$ 时，训练误差期望为 $3.6$，新标签误差期望为 $4.4$。

由讲义的两个期望公式，
$$3.2=\sigma^2(1-p/40),\qquad4.8=\sigma^2(1+p/40).$$
相加得 $8=2\sigma^2$，相减得 $1.6=2\sigma^2p/40$，于是求得 $\sigma^2=4,p=8$。代入新的样本数得到 $4(1-8/80)=3.6$ 和 $4(1+8/80)=4.4$。

区分点：两个期望之和确定噪声，差确定参数比例；这些等式依赖于真实函数在列空间内，也不能把一次观测误差当成精确期望。

**M3-07**
**答案：** 原流程泄漏。全体统计量为 $\mu=6,s=\sqrt{26}$，把 $F_1$ 变成 $(-6/\sqrt{26},-4/\sqrt{26})$。正确流程验证 $F_1$ 时用 $\mu=11,s=1$，验证 $F_2$ 时用 $\mu=1,s=1$；因此 $F_1$ 应变成 $(-11,-9)$。最终重新训练时可以使用全部四个输入重新计算统计量。

全体方差为 $(36+16+16+36)/4=26$。验证 $F_1$ 时只能从训练折 $F_2$ 计算均值和方差，所以均值为 $11$，方差为 $1$；反过来验证 $F_2$ 时，训练折均值为 $1$，方差也为 $1$。

即使没有使用标签，验证输入也参与了原流程的统计量计算。选完超参数后，四个样本都属于最终训练数据，重新计算统计量不涉及未使用的测试集。

区分点：判断泄漏要追踪统计量由哪些样本算出，不能只检查是否碰过验证标签。

**M3-08**
**答案：** 等式成立；独立性用于消去噪声与预测误差的交叉项。

先把 $Y-\hat f=\varepsilon+(a-\hat f)$ 平方并取期望，得到
$$E[(Y-\hat f)^2]=\sigma^2+2E[\varepsilon(a-\hat f)]+E[(a-\hat f)^2].$$
因为独立且 $E\varepsilon=0$，中间一项为 $2E\varepsilon\,E(a-\hat f)=0$。

再写 $a-\hat f=(a-m)+(m-\hat f)$。其中 $a-m$ 是常数，而 $E(m-\hat f)=0$，所以
$$E[(a-\hat f)^2]=(a-m)^2+E[(m-\hat f)^2]=(a-m)^2+\mathrm{Var}(\hat f).$$
代回即可。第二次消去交叉项只用了均值的定义，不需要额外的独立性。

区分点：要分别交代两个交叉项消失的依据；均值为零本身不能保证两个随机量乘积的期望为零。

**M3-09**
**答案：** 原结果不正确；真正的解是 $(5/4,0)^{\mathsf T}$，目标值为 $15/8$，原候选的目标值为 $3$。

因为 $X^{\mathsf T}X=\operatorname{diag}(4,1)\ne I$，列虽然正交，却不是单位正交，不能对最小二乘解直接使用相同阈值。

目标可以写成
$$J=2(w_1-3/2)^2+|w_1|+\frac12(w_2+1)^2+|w_2|.$$
第一坐标的部分除以 $4$ 后不改变该坐标的最小值点，变成 $\frac12(w_1-3/2)^2+\frac14|w_1|$，故阈值为 $1/4$，得到 $w_1=5/4$。第二坐标仍用阈值 $1$，得到 $w_2=0$。

代回时，第二坐标虽为零，残差项仍贡献 $1/2$，所以
$$J(5/4,0)=\frac18+\frac54+\frac12=\frac{15}{8},\qquad
J(1/2,0)=2+\frac12+\frac12=3.$$

区分点：先检查二次项的系数，才能确定每个坐标的阈值；“正交”少了“单位”仍会算错。

**M3-10**
**答案：** $\tau^2=3/2,\kappa=2$；$\widetilde\lambda_2=1/3,\widetilde\lambda_1=1/4$。两个最优解都不变。

先对齐讲义的系数。L2 惩罚中的 $2w^2$ 等于 $\lambda_2w^2/2$，所以 $\lambda_2=4$，由 $\lambda_2=\sigma^2/\tau^2$ 得 $\tau^2=6/4=3/2$。L1 中 $\lambda_1=3$，故 $\kappa=\sigma^2/\lambda_1=2$。

整个目标除以 $12$ 后，惩罚系数也必须除以 $12$，所以 $\widetilde\lambda_2=4/12$，$\widetilde\lambda_1=3/12$。因为乘以正常数不改变大小关系，所以不会改变最小值点。

区分点：先辨认 L2 系数里的 $1/2$，再把整个目标一起缩放；只把误差改成平均会改变正则化强度。

**M3-11**
**答案：** 原 AUC 等于 $5/8$ 时只有 $t=0$；取反后的 AUC 等于 $5/8$ 时只有 $t=2$。完整表达式为
$$\mathrm{AUC}(t)=
\begin{cases}
3/4,&t<0,\\
5/8,&t=0,\\
1/2,&0<t<2,\\
3/8,&t=2,\\
1/4,&t>2.
\end{cases}$$
与负例分数 $1$ 比较时，两个正例合计胜 $1$ 对。与 $t$ 比较时，上面五种情形的得分依次为 $2,3/2,1,1/2,0$；分别加 $1$ 再除以 $4$，便得到分段式。

这里的 $t$ 始终表示取反前的负例分数；取反后正例分数为 $0,-2$，负例分数为 $-1,-t$。分数取反使每个严格胜负互换，并列仍计半对，因此新 AUC 为 $1-\mathrm{AUC}(t)$。它等于 $5/8$，就要求原 AUC 为 $3/8$，对应原参数 $t=2$。

区分点：临界分数处不能沿用任一侧的严格不等式；递减变换会翻转排序。

### C 提高

**M3-12**
**答案：** 无惩罚时的全部解为 $(u,2-u)^{\mathsf T}$，$u\in\mathbb R$。$\lambda>0$ 时两个特征值为 $\lambda,\lambda+4$，唯一解为
$$\boldsymbol w_\lambda=\frac4{4+\lambda}\begin{pmatrix}1\\1\end{pmatrix}.$$
它趋于 $(1,1)^{\mathsf T}$，恰好是无惩罚解中长度最小的一个；不能把 $\lambda=0$ 直接代入矩阵逆。

因为 $X\boldsymbol w=(w_1+w_2,-w_1-w_2)^{\mathsf T}$，所以无惩罚目标为 $(2-w_1-w_2)^2$，最小时只要求 $w_1+w_2=2$。

又有
$$X^{\mathsf T}X+\lambda I=
\begin{pmatrix}2+\lambda&2\\2&2+\lambda\end{pmatrix},\qquad
X^{\mathsf T}\boldsymbol y=\begin{pmatrix}4\\4\end{pmatrix}.$$
向量 $(1,-1)^{\mathsf T}$、$(1,1)^{\mathsf T}$ 分别给出特征值 $\lambda,\lambda+4$。两者都为正，所以最小值点唯一。正规方程两行相减得 $\lambda(w_1-w_2)=0$，故 $w_1=w_2=4/(4+\lambda)$。

无惩罚解的长度平方为 $u^2+(2-u)^2=2(u-1)^2+2$，只有 $u=1$ 时最小。极限虽然存在，但 $\lambda=0$ 时矩阵有零特征值，逆不存在。

区分点：无惩罚时预测值可以唯一而参数不唯一；正则化解的极限存在，不代表极限处的矩阵仍可逆。

**M3-13**
**答案：** 验证 $F_1,F_2$ 时的系数依次为 $6/(2+\lambda),2/(2+\lambda)$，并且
$$V(\lambda)=\frac{20}{(2+\lambda)^2}-\frac{12}{2+\lambda}+6.$$
最优 $\lambda=4/3$，$V=21/5$；重新训练得到 $w=3/2$，不等于两折系数的平均 $6/5$。

每轮有两个训练样本，令目标导数为零得 $(2+\lambda)w=\sum_{i\in T}y_i$。两折验证误差分别为 $w^2-2w+2$ 和 $w^2-6w+10$，代入各自的系数再取平均，就得到 $V$。

令 $r=2+\lambda\ge2$。对 $r$ 求导，
$$\frac{\mathrm dV}{\mathrm dr}=\frac{12r-40}{r^3}.$$
导数在 $r=10/3$ 左侧为负、右侧为正，所以该点给出全局最小值，进而 $\lambda=4/3$。

最终训练用四个样本，正规方程变成 $(4+\lambda)w=8$，得到 $w=3/2$。两折的系数则为 $9/5,3/5$，平均只有 $6/5$。

区分点：交叉验证平均的是验证误差；选出超参数后，要用全部数据重新求解，不能把各折参数平均后交付。

### 章末混合练习

**M3-14**
**答案：** $w_1=3/4,w_2=9/8$；递推式为 $w_{t+1}=w_t/2+3/4$，固定点为 $3/2$，并有 $w_t=\frac32(1-2^{-t})$。极限为 $0$ 的说法错误。

这里结合 M.1 的梯度下降与本章方法 2 的 L2 惩罚。总导数为 $(w-3)+w=2w-3$，所以一次更新是
$$w_{t+1}=w_t-\frac14(2w_t-3)=\frac12w_t+\frac34.$$
从两边减去固定点 $3/2$，得到 $w_{t+1}-3/2=(w_t-3/2)/2$。每一步误差减半，由初值便得到通项及极限。只乘 $3/4$ 漏掉了数据损失的梯度，它仍在把权重推向拟合数据的方向。

区分点：权重衰减只是完整更新的一部分；求极限要找整个更新的固定点。

**M3-15**
**答案：** 后验为 $N(1,1/2)$，所以均值和 MAP 都是 $1$，方差为 $1/2$；最大似然估计为 $2$。

这里结合 M.2 的高斯似然、本章方法 2 的 MAP 解释与配方。似然乘先验后，
$$p(w\mid1,3)\propto
\exp\!\left[-\frac{(1-w)^2+(3-w)^2}{4}-\frac{w^2}{2}\right]

因为高斯密度的指数为 $-(w-\mu)^2/(2v)$，所以 $\mu=1,v=1/2$。最大似然只最小化平方误差，得到两次观测的均值 $2$。

再用 $\lambda=\sigma^2/\tau^2=2$ 核对：$X=(1,1)^{\mathsf T}$，因此 $w_{\mathrm{MAP}}=(1+3)/(2+2)=1$。

**M3-16**
**答案：** 两组 AUC 都为 $3/4$。$\boldsymbol p$ 的准确率、精确率都是 $1/2$；$\boldsymbol q$ 的准确率为 $3/4$、精确率为 $2/3$。
