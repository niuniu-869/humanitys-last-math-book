## M.13 · 预训练与大模型：自监督、微调、上下文学习与 scaling law（速记）

| 提示 | 内容 |
|---|---|
| 自监督 | 标签从数据自身造出：前文 → 下一个词，或遮住再猜；$T\ge2$ 个词元造出 $T-1$ 对（目标是第 2 至第 $T$ 个词元）；每对的损失 $=\ln\sum_je^{z_j}-z_k$ |
| 因果语言模型 | $L=-\frac1{T-1}\sum_{t=2}^{T}\ln p_\theta(x_t\mid x_{<t})$；可见关系是含对角线的下三角；条件连乘再乘首词概率才是整句概率，可生成 |
| 掩码语言模型 | $L=-\frac1{\lvert M\rvert}\sum_{t\in M}\ln p_\theta(x_t\mid\widetilde x)$，$\widetilde x$ 是替换后的完整输入（80% 掩记号、10% 随机词、10% 原样）；约 15% 位置，两侧都看，可见关系全 1，不能逐词续写 |
| 微调 | 从预训练参数 $\theta_0$ 出发，在小数据上继续下降，学习率常取小一些，可能缓解灾难性遗忘，但不保证 |
| 指令微调 SFT | $L_{\text{SFT}}=\sum_{t=2}^{T} m_t\ell_t/\sum m_t$（分母 $>0$），$m_t=1$ 只在回答（通常含结束符）位置；指令只作前文，不产生损失 |
| 上下文学习 | 参数不变，把例子写进输入：$p_\theta(y\mid\text{例子},x)$；按示例数分零样本、单样本、少样本，另一维度是是否写中间步骤（思维链）；多输出一个词元，主项约多 $2N$ 次运算 |
| 幂律与双对数 | $L=CN^{-\alpha}$（$C=N_c^{\alpha}$），$\ln L=\ln C-\alpha\ln N$：双对数图上是直线，斜率 $-\alpha$；两点定指数 $\alpha=\ln(L_1/L_2)/\ln(N_2/N_1)$ |
| 规模每乘 10 | 损失乘 $10^{-\alpha}$；$\alpha=0.1$ 时降约 21%；有下不去的底 $E$ |
| 计算最优 | $L=E+AN^{-a}+BD^{-b}$，$A,B,a,b,c>0$，计算量 $C_{\text{comp}}\approx6ND$、$c=C_{\text{comp}}/6$ 固定，代入 $D=c/N$，导数先负后正，唯一最小点 $N_*^{a+b}=\frac{aA}{bB}c^{b}$，$N$、$D$ 一起长 |
| LoRA | $W=W_0+BA$，$B\in\mathbb R^{d\times r}$、$A\in\mathbb R^{r\times k}$，只训练 $B,A$：$r(d+k)$ 个参数；$B=0$ 初始化，秩至多 $r$，训练后可并回 |
| MoE | $n_e$ 个专家，门控打分，取最高 $k_e$ 个，对这 $k_e$ 个分数做 softmax 当权重；总参数大、每词元只激活 $k_e$ 个 |
| 量化 | $s=m/(2^{b-1}-1)$，$q=\operatorname{round}(w/s)$，整组全 0 时码和还原值取 0；误差 $\le s/2$；离群值抬高 $s$，所以按小组各用一个 $s$ |
| 易错 | SFT 的分母只数回答位置；遮住再猜的各位置双向条件概率不能连乘成整句概率；LoRA 的 $B$ 和 $A$ 不能同时取零（梯度全为零） |
