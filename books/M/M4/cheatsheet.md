| 提示 | 内容 |
|---|---|
| k 近邻 | 取离新点最近的 $k$ 个训练样本投票；$k=1$ 方差大、训练误差为 0（特征不重复时）；$k=n$ 偏差大；$k$ 用交叉验证挑；先标准化 |
| 余弦与欧氏距离 | 向量先归一化后 $\lVert\boldsymbol a-\boldsymbol b\rVert^2=2-2\cos\theta$，两种排序一致；长度会干扰欧氏距离，长向量可能被排到后面 |
| 球壳体积 | $d$ 维球最外 $\varepsilon$ 厚的壳占体积 $1-(1-\varepsilon)^d$，$d$ 大时趋近 1；盖住 $p$ 比例数据的方块边长 $p^{1/d}$ |
| 距离集中 | $[0,1]^d$ 里两随机点距离平方均值 $d/6$、方差 $7d/180$，相对标准差 $\sqrt{1.4/d}\to0$：最近与最远几乎一样远 |
| 熵与信息增益 | $H=-\sum p\log_2p$；条件熵 $H(Y\mid X)=\sum_xP(x)H(Y\mid X=x)$；$\mathrm{IG}=H(Y)-H(Y\mid X)=I(X;Y)\ge0$，选最大的 |
| 树的毛病 | 全拟合的深树方差大；编号类特征 IG 最大却无用（用增益率）；用深度、叶子大小、剪枝控制，验证集挑 |
| 自助样本 | 有放回抽 $n$ 次，某样本没被抽到的概率 $(1-1/n)^n\to e^{-1}\approx0.368$，约 63.2% 被抽到；没抽到的是袋外样本 |
| bagging 方差 | $B$ 个方差 $\sigma^2$、两两相关 $\rho$ 的量平均：$\rho\sigma^2+(1-\rho)\sigma^2/B$；$B$ 再大也降不到 $\rho\sigma^2$ 以下；偏差不变 |
| 随机森林 | 每次分裂只在随机抽出的 $m$ 个特征里选（分类 $\approx\sqrt d$，回归 $\approx d/3$），降低 $\rho$，单棵树略差 |
| 梯度提升 | $F\leftarrow F+\eta h$，$h$ 拟合损失对当前预测的负梯度：平方损失是残差 $y-F$，交叉熵（$F$ 是对数几率）是 $y-p$ |
| bagging 与提升 | bagging 并行平均深树降方差；提升串行累加浅树降偏差，轮数太多会过拟合，需提前停止；$\eta$ 小则轮数多 |
| k-means | 目标 $J=\sum\lVert\boldsymbol x_i-\boldsymbol\mu_{c(i)}\rVert^2$；交替「分给最近中心」「中心移到平均」，每步 $J$ 不增，有限步停；均值最小化平方距离和 |
| k-means 的局限 | 只保证局部最优（初值不同结果不同），要多次初值或 k-means++；$K$ 要事先定；对尺度敏感；只适合团状的堆 |
