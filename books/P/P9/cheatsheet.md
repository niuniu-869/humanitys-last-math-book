## P.9 · 马尔可夫链（速记）

| 提示 | 内容 |
|---|---|
| 马尔可夫性 | $P(X_{n+1}=j\mid X_n=i,\text{全部历史})=P(X_{n+1}=j\mid X_n=i)=p_{ij}$；现在已知时，过去与将来条件独立；历史有限步时，打包成新状态 |
| 路径概率 | $P(X_0=i_0,\dots,X_n=i_n)=P(X_0=i_0)\,p_{i_0i_1}\cdots p_{i_{n-1}i_n}$ |
| 转移矩阵 | $P=(p_{ij})$，元素非负，第 $i$ 行是从 $i$ 出发的分布，**每行和为 1**（列和不必为 1）；分布是行向量，$\pi_{n+1}=\pi_nP$；L.12 的列和为 1 的 $M$ 是 $P^{\mathsf T}$ |
| 走 $n$ 步 | $p_{ij}^{(m+n)}=\sum_kp_{ik}^{(m)}p_{kj}^{(n)}$，所以 $P^{(n)}=P^n$（矩阵幂，不是元素的幂）；$\pi_n=\pi_0P^n$ |
| 两状态链 | $0\le a,b\le1$，$a+b>0$（$a=b=0$ 时 $P=I$），$P=\begin{pmatrix}1-a&a\\b&1-b\end{pmatrix}$：$n\ge1$ 时$\pi=\big(\tfrac b{a+b},\tfrac a{a+b}\big)$，$\lambda=1-a-b$，$P^n=\Pi+\lambda^n(I-\Pi)$，$\Pi$ 的两行都是 $\pi$ |
| 吸收概率 | 前提：有限状态，每个非吸收态都能沿正概率路径到达吸收态。一步分析：$h_i=\sum_jp_{ij}h_j$，目标吸收态 $h=1$，其他吸收态 $h=0$；各出口概率之和为 1 |
| 赌徒输光 | 各局独立，$0<p<1$，$N\ge2$（$p=0,1$ 时结论直接看出），每局赢的概率 $p$，从 $i$ 到 $N$：$p=\tfrac12$ 时 $h_i=\tfrac iN$；$p\ne\tfrac12$ 时 $h_i=\dfrac{1-r^i}{1-r^N}$，$r=\tfrac qp$ |
| 期望吸收时间 | 同吸收概率的前提。$m_i=1+\sum_{j\,\text{暂态}}p_{ij}m_j$（吸收态 $m=0$）；矩阵形式 $\boldsymbol m=(I-Q)^{-1}\boldsymbol1$；公平赌局 $m_i=i(N-i)$ |
| 平稳分布 | $\pi P=\pi$，$\pi(i)\ge0$，$\sum\pi(i)=1$；$P$ 的左特征向量。方程不独立，去掉一个再补归一化；解 $(P-I)\boldsymbol x=\boldsymbol0$ 得到的是右特征向量（$\boldsymbol1$ 总是解），不能凭它认定平稳分布，仍须检查 $\pi P=\pi$ |
| 平稳分布的读法 | 不再变化的分布；长期的时间比例；进出平衡；有限、不可约的链里，平均回访时间 $=1/\pi(i)$ |
| 收敛条件 | 有限、不可约、非周期 $\Rightarrow$ 平稳分布唯一且 $\pi_0P^n\to\pi$；缺少条件时结论不再有保证，需另行判断（周期链从平稳分布出发恒定；吸收态各自封闭则没有与起点无关的共同极限） |
| 泊松过程 | $N(0)=0$，独立增量，$N(t+s)-N(s)\sim\mathrm{Pois}(\lambda t)$；到达间隔独立同服从 $E(\lambda)$（无记忆）；第 $k$ 次到达 $\le t\iff N(t)\ge k$；独立叠加强度相加 |
| 维纳过程 | $W(0)=0$，独立增量，$W(t)-W(s)\sim N(0,t-s)$，路径连续；$\mathrm{Cov}(W(s),W(t))=\min(s,t)$；步长取时间间隔的平方根 |
