## P.12 · 假设检验（速记）

| 提示 | 内容 |
|---|---|
| 检验的逻辑 | 先设 $H_0$，算它成立时数据这样极端的概率；很小就拒绝。拒绝是强结论；不拒绝只是证据不足，不等于证明 $H_0$ 成立 |
| 四步 | 立 $H_0,H_1$；选检验统计量（$H_0$ 下分布已知）；按 $H_1$ 方向与 $\alpha$ 定拒绝域；比较观察值 |
| 拒绝域的位置 | 数据哪一端更支持 $H_1$，拒绝域放在哪一端；双侧每边 $\frac\alpha2$；单侧还是双侧要在看数据之前选 |
| p 值 | $H_0$ 成立时出现至少这样极端的结果的概率；$p\le\alpha\iff$ 拒绝；双侧对称时是单尾的 2 倍 |
| p 值易错 | 不是 $H_0$ 为真的概率（在 $H_0$ 下至少同样极端的事件概率，$\ne P(H_0\mid\text{数据})$）；小不等于差别大（$n$ 大时微小差别也显著）；连续统计量的检验中 $H_0$ 为真时 $p$ 均匀分布 |
| 两类错误 | 第一类（弃真）概率 $\alpha$；第二类（取伪）概率 $\beta$，依赖真值；功效 $1-\beta$；$\alpha$ 取小则 $\beta$ 变大，固定其他条件时 $n$ 增大可改善两者 |
| $\alpha$ 与 p 值 | $\alpha$ 事先定、是误拒概率的上限；p 值看数据后算、是证据强度 |
| 均值检验 | $\sigma$ 已知 $U=\frac{\bar X-\mu_0}{\sigma/\sqrt n}\sim N(0,1)$；未知 $T=\frac{\bar X-\mu_0}{S/\sqrt n}\sim t(n-1)$；双侧 $\lvert T\rvert>t_{\alpha/2}$，右侧 $T>t_\alpha$，左侧 $T<-t_\alpha$ |
| 两组均值 | 独立（方差相同）：$T=\frac{\bar X-\bar Y}{S_w\sqrt{1/n_1+1/n_2}}\sim t(n_1+n_2-2)$；同一批对象的成对数据：取差后单样本 $t(n-1)$，不要当成两个独立样本；方差差得多且大方差在小样本组时，合并 $t$ 的误拒概率远超 $\alpha$ |
| 方差检验 | $\chi^2=\frac{(n-1)S^2}{\sigma_0^2}\sim\chi^2(n-1)$，右侧用 $\chi^2_\alpha$，左侧用 $\chi^2_{1-\alpha}$，双侧两端各 $\alpha/2$；$F=\frac{S_1^2}{S_2^2}\sim F(n_1-1,n_2-1)$，双侧时大的放分子，与 $F_{\alpha/2}$ 比；对非正态敏感 |
| 对偶 | 双侧水平 $\alpha$ 检验不拒绝 $\mu_0\iff\mu_0$ 在 $1-\alpha$ 置信区间内；区间就是所有不被拒绝的 $\mu_0$；报告检验时附区间 |
| 样本容量 | 单侧 $n\ge\big(\frac{(z_\alpha+z_\beta)\sigma}\delta\big)^2$，双侧用 $z_{\alpha/2}$（保守的近似）；比例（两组）$n\ge\frac{(z_{\alpha/2}+z_\beta)^2[p_1(1-p_1)+p_2(1-p_2)]}{(p_2-p_1)^2}$；$n\propto1/\delta^2$ |
| 拟合优度 | $\chi^2=\sum\frac{(O_i-E_i)^2}{E_i}$，自由度 $k-1-r$（$r$ 为估计的参数个数），只看右尾，要求 $E_i\ge5$ |
| 自助法 | 有放回抽 $n$ 个重算统计量，重复 $B$ 次；2.5% 与 97.5% 分位数为 95% 区间；成对数据按对重抽；区间不含 0 就拒绝「无差别」 |
