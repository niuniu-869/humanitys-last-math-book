## P.2 · 条件概率与独立（速记）

| 提示 | 内容 |
|---|---|
| 条件概率 | $P(A\mid B)=\dfrac{P(AB)}{P(B)}$（$P(B)>0$）：只看 $B$ 这一块，放大回总量 1，$A$ 在里面占多大；条件是谁，谁就是分母 |
| 缩小样本空间 | 古典概型里 $P(A\mid B)=\#(AB)/\#B$；条件概率仍满足三条公理，P.1 的性质（对立、加法）照样用 |
| 三个易混的数 | $P(A\mid B)$、$P(B\mid A)$、$P(AB)$ 分子相同、分母不同；一般 $P(A\mid B)\ne P(B\mid A)$ |
| 乘法公式 | $P(AB)=P(A)P(B\mid A)$；$P(A_1\cdots A_n)=P(A_1)P(A_2\mid A_1)\cdots P(A_n\mid A_1\cdots A_{n-1})$；语言模型的连乘 |
| 全概率公式 | $B_1,\dots,B_n$ 完备事件组：$P(A)=\sum P(B_i)P(A\mid B_i)$；画树，沿通向 $A$ 的路相乘再相加；是 $P(A\mid B_i)$ 的加权平均。路线有重叠会重复计算，有遗漏会少算 |
| 贝叶斯公式 | $P(B_k\mid A)=\dfrac{P(B_k)P(A\mid B_k)}{\sum P(B_i)P(A\mid B_i)}$：通向 $A$ 的路里经过 $B_k$ 的份额；先验 $\to$ 后验，各后验之和为 1 |
| 老朋友② | 患病率 1%，检出率 95%，误判率 5%：$P(\text{阳})=0.059$，$P(\text{病}\mid\text{阳})=\tfrac{19}{118}\approx16.1\%$；先验越小，后验越小，患病率低于 5% 时阳性者多半没病 |
| 独立 | $P(AB)=P(A)P(B)$，$P(B)>0$ 时等价于 $P(A\mid B)=P(A)$（放大前后占比不变）；$A,B$ 独立则 $A,\overline B$ 等也独立 |
| 独立与互斥 | 概率都大于 0 的互斥事件一定不独立（$P(AB)=0\ne P(A)P(B)$） |
| 相互独立 | 三个事件要四个等式（三个两两加 $P(ABC)=P(A)P(B)P(C)$）；两两独立推不出相互独立（抛两枚硬币，$C$＝结果相同） |
| 独立时的算法 | 同时发生相乘；至少一个：$1-\prod(1-p_i)$ |
| $n$ 重伯努利试验 | 两种结果、$p$ 不变、各次独立：$P_n(k)=\binom nkp^kq^{n-k}$（$q=1-p$）；各项之和 $=(p+q)^n=1$；至少一次 $1-q^n$。$p$ 逐次变化、不放回抽取都不能用 |
| 第 $k$ 次成功恰在第 $n$ 次 | $\binom{n-1}{k-1}p^kq^{n-k}$：最后一次必须成功，前 $n-1$ 次里恰有 $k-1$ 次 |
| 条件独立 | $P(AB\mid C)=P(A\mid C)P(B\mid C)$；独立推不出条件独立（两枚硬币，$C$＝恰有一正），条件独立也推不出独立（两次检测） |
| 易错 | 把 $P(A\mid B)$ 当 $P(B\mid A)$；全概率里的 $B_i$ 不是完备事件组；把两两独立当相互独立；把互斥当独立 |
