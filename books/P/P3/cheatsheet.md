## P.3 · 离散随机变量（速记）

| 提示 | 内容 |
|---|---|
| 随机变量 | 样本点到实数的函数 $X(\omega)$；$\{X=k\}$ 是使 $X$ 取 $k$ 的全部结果组成的事件；先把事件翻译成关于 $X$ 的式子，再在样本空间上算概率 |
| 分布律 | $p_k=P(X=x_k)$；$p_k\ge0$，$\sum p_k=1$（没算对先查总和）；$P(X\in A)=\sum_{x_k\in A}p_k$ |
| 0-1 分布 | $P(X=1)=p$，$P(X=0)=1-p$，记 $B(1,p)$；一次试验成不成功 |
| 分布函数 | $F(x)=P(X\le x)$；单调不减，$F(-\infty)=0$，$F(+\infty)=1$，右连续；离散时是阶梯，跳高 = 该点概率 |
| 用 $F$ 算概率 | 总规则：带等号取 $F(a)$，不带等号取 $F(a-0)$；$P(a<X\le b)=F(b)-F(a)$（左开右闭）；$P(X=a)=F(a)-F(a-0)$；$P(X<a)=F(a-0)$ |
| 二项 $B(n,p)$ | $P(X=k)=\binom nkp^kq^{n-k}$；四个条件：固定 $n$、两结果、$p$ 不变、独立；$n=1$ 是 0-1 分布 |
| 二项最可能值 | 比值 $\frac{P(k)}{P(k-1)}=\frac{(n-k+1)p}{kq}$；$(n+1)p$ 非整数时取 $\lfloor(n+1)p\rfloor$，是整数时 $(n+1)p-1$ 与 $(n+1)p$ 并列 |
| 几何 $G(p)$ | 第一次成功在第 $k$ 次：$q^{k-1}p$；$P(X>k)=q^k$，$P(X\le k)=1-q^k$ |
| 无记忆性 | $P(X>m+n\mid X>m)=P(X>n)$；已失败 $m$ 次不改变还要等多久（来自独立性，不是「该中了」） |
| 超几何 $H(N,D,n)$ | 不放回抽样：$\frac{\binom Dk\binom{N-D}{n-k}}{\binom Nn}$；$k$ 的范围 $\max(0,n-N+D)\le k\le\min(n,D)$；$N$ 很大时近似 $B(n,\frac DN)$ |
| 泊松 $P(\lambda)$ | $P(Y=k)=\frac{\lambda^k}{k!}e^{-\lambda}$；区间变长 $t$ 倍则 $\lambda\to t\lambda$；$n$ 大 $p$ 小时近似 $B(n,p)$，取 $\lambda=np$ |
| 选哪个分布 | 数成功次数且 $n$ 固定 → 二项；等第一次成功 → 几何；不放回抽检 → 超几何；稀有事件的计数 → 泊松 |
| 易错 | 平均 3 个不等于恰好 3 个；$F(a)$ 带等号而 $P(X<a)$ 不带；不放回抽样不能直接用二项 |
