## C.8 · 用导数研究函数（速记）

| 提示 | 内容 |
|---|---|
| 单调性判别 | $f'>0$ 增，$f'<0$ 减；$f'\ge0$ 且 $f'$ 不在任何长度大于零的子区间上恒为零时仍严格增；由拉格朗日中值定理 $f(x_2)-f(x_1)=f'(\xi)(x_2-x_1)$；严格增只能推出 $f'\ge0$，不能推出处处 $f'>0$（$x^3$） |
| 证不等式 | $g=\text{左}-\text{右}$，选基准点 $a$（如左端点处 $g(a)=0$），$x>a$ 时 $g'>0$ 即得 $g>0$（基准点在右侧则方向相反）；$g'$ 看不出符号就对 $g'$ 再做一次（$\sin x>x-\frac{x^3}6$ 要三层） |
| 极值候选 | 驻点（$f'=0$）和导数不存在的点；驻点不一定是极值点（$x^3$），极值点不一定是最值点 |
| 第一充分条件 | $f'$ 经过 $x_0$ 由正变负为极大，由负变正为极小，两侧都严格正或都严格负则没有极值，其他情形回到定义；要求候选点连续、两侧可导，尖点也适用 |
| 第二充分条件 | $f'(x_0)=0$：$f''>0$ 极小，$f''<0$ 极大；$f''(x_0)=0$ 无结论，看第一个非零的 $f^{(n)}(x_0)$：$n$ 偶数有极值，$n$ 奇数没有 |
| 闭区间最值 | 比较驻点、不可导点和两个端点的函数值，最大的是最大值，最小的是最小值；候选点有限时逐个比较；开区间里若函数连续、先减后增，则该点是最小值点（先增后减则是最大值点） |
| 建模步骤 | 写成一元函数并写清取值范围；求导；用整个区间上的增减说明是全局最值；回答题目问的量 |
| 凸与凹（本书叫法） | $f''>0$ 凸（碗形，弦在上、切线在下）；$f''<0$ 凹；其他书把 $f''>0$ 叫凹，只记图不记字 |
| 凸函数的性质 | 弦在曲线上方（$f(\lambda x_1+(1-\lambda)x_2)\le\lambda f(x_1)+(1-\lambda)f(x_2)$）；$f''\ge0$ 是凸的充分条件（$\lvert x\rvert$ 凸而无二阶导），此时曲线在切线上方，驻点是全局最小值点（但不保证存在或唯一） |
| 拐点 | 曲线上凸凹性改变的点，写两个坐标；候选是 $f''=0$ 和 $f''$ 不存在的点，两侧变号才是（$x^4$ 不是，$x^{1/3}$ 是） |
| 渐近线 | 铅直：单侧极限为 $\infty$（分母为零不一定是，$\frac{x^2-1}{x-1}$ 在 1 处极限是 2）；水平：$\lim f=b$；斜：$k=\lim\frac fx$，$b=\lim(f-kx)$，$\pm\infty$ 分开算 |
| 作图五步 | 定义域与对称、渐近线、$f'$ 的符号表、$f''$ 的符号表、合表连线 |
| 根的个数 | 分离参数 $g(x)=k$，画 $g$ 的图看与水平线的交点；每个单调段两端的极限要查（$e^x=kx$：$k<0$ 一根，$0\le k<e$ 无，$k=e$ 一根，$k>e$ 两根） |
| 牛顿法 | $x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}$；二阶连续可导、$f'(r)\ne0$、初值足够近时 $|x_{n+1}-r|\le\frac M{2m}|x_n-r|^2$；初值太远会失败（$x^3-2x+2$ 从 0 出发在 0、1 之间跳）；$f'(r)=0$ 时（$x^2=0$）每步只缩小一半 |
| 曲率 | $K=\frac{\lvert y''\rvert}{(1+y'^2)^{3/2}}$，$K>0$ 时 $\rho=\frac1K$；$\mathrm ds=\sqrt{1+y'^2}\,\mathrm dx$ |
