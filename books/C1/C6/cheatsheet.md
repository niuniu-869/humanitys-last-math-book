## C.6 · 微分中值定理（速记）

| 提示 | 内容 |
|---|---|
| 极值与驻点 | 局部极大：附近都有 $f(x)\le f(x_0)$；导数为 0 的点叫驻点 |
| 费马引理 | $f$ 在 $x_0$ 取极值且**可导**，则 $f'(x_0)=0$；证明用左割线 $\ge0$、右割线 $\le0$ 夹出 0 |
| 费马的边界 | 驻点不一定是极值（$x^3$）；极值点不一定可导（$\lvert x\rvert$）；区间端点的极值不适用 |
| 罗尔定理 | $[a,b]$ 连续、$(a,b)$ 可导、$f(a)=f(b)$ $\Rightarrow$ $\exists\xi\in(a,b)$，$f'(\xi)=0$；证明：最值定理 + 费马引理 |
| 罗尔的三个条件 | 缺连续（端点断开）、缺可导（$\lvert x\rvert$ 在 $[-1,1]$）、缺等高（$f(x)=x$）：分别有反例说明结论不再保证成立 |
| 用罗尔数根 | 至多几个根：反设多根，相邻两根间 $f'$ 有零点，与 $f'$ 的零点个数矛盾；$f$ 有 $n$ 个零点 $\Rightarrow$ $f'$ 至少 $n-1$ 个 |
| 拉格朗日 | $f(b)-f(a)=f'(\xi)(b-a)$；几何：有一点切线与弦平行；证明：$\varphi=f-f(a)-k(x-a)$（曲线减弦）+ 罗尔 |
| 推论 | 同一区间上 $f'\equiv0$ 则 $f$ 为常数；$f'=g'$ 则 $f-g$ 为常数（需连续到端点时另加连续条件）；$\arcsin x+\arccos x=\frac\pi2$；$x\ne0$ 上 $\arctan x+\arctan\frac1x$ 在两侧常数不同（$\pm\frac\pi2$） |
| 证不等式 | 把差写成 $f(b)-f(a)$，用 $f'(\xi)$ 的范围卡住；$\frac x{1+x}<\ln(1+x)<x$（$x>0$） |
| 柯西 | $\frac{f(b)-f(a)}{g(b)-g(a)}=\frac{f'(\xi)}{g'(\xi)}$，$g'\ne0$；$g=x$ 时是拉格朗日；不能对分子分母各用一次拉格朗日（点不同）；$g'\ne0$ 是写成比值的充分条件，交叉乘积式只需连续可导 |
| 反推辅助函数 | $\xi f'+f=0\to xf$；$\xi f'-f=0\to f/x$；$f'+\lambda f=0\to e^{\lambda x}f$；$f'+g'f=0\to e^{g}f$；$f'g+fg'=0\to fg$ |
| 乘什么因子 | 要把 $f'+pf$ 变成 $(uf)'$，需要 $u'=pu$，所以 $p=\lambda$ 时 $u=e^{\lambda x}$，$p=g'$ 时 $u=e^{g}$ |
| 要两个点 | 一次定理只给一个 $\xi$：找分点 $c$，在两段上各用一次中值定理 |
| 三个定理的关系 | 罗尔 $\subset$ 拉格朗日 $\subset$ 柯西；证明次序反过来 |
