## C.14 · 常数项级数（速记）

| 提示 | 内容 |
|---|---|
| 收敛的定义 | 部分和 $S_n=u_1+\cdots+u_n$ 的极限存在，极限就是和；敛散是数列 $S_n$ 的极限问题 |
| 等比级数 | $\sum\limits_{n=0}^\infty aq^n=\frac a{1-q}$（首项除以 $1-$公比），$a\ne0$ 时仅当 $\lvert q\rvert<1$ 收敛，其余情形发散 |
| 裂项 | 通项拆成 $v_n-v_{n+k}$，中间相消，$S_n$ 只剩头尾；$\frac1{n(n+2)}=\frac12(\frac1n-\frac1{n+2})$，和 $\frac34$ |
| 必要条件 | 收敛 $\Rightarrow u_n\to0$；通项不趋于 0 一定发散；反过来不成立（调和级数、$\sum\ln(1+\frac1n)$） |
| 基本性质 | 线性性；改变有限项不改变敛散性；收敛级数任意加括号仍收敛，反之不然（$(1-1)+(1-1)+\cdots$） |
| 正项级数 | 收敛 $\iff$ 部分和有上界（单调有界）；先看通项，再选判别法 |
| 积分判别与 $p$ 级数 | $f$ 在 $[1,+\infty)$ 上连续、正、单调不增，$\sum f(n)$ 与 $\int_1^{+\infty}f$ 同敛散；单调这一条不能去（$\sin^2\pi x$ 反例）；$\sum\frac1{n^p}$：$p>1$ 收敛，$p\le1$ 发散；级数收敛时余项 $\int_{N+1}^{+\infty}f\le R_N\le\int_N^{+\infty}f$ |
| 对数边界 | $n\ge2$：$\sum\frac1{n\ln n}$ 发散，$\sum\frac1{n(\ln n)^2}$ 收敛（仍要计算积分，不能只看多了一个对数因子） |
| 比较判别法 | $0\le u_n\le v_n$（$u_n\ge0$ 不能去）：大的收敛则小的收敛，小的发散则大的发散；极限形式 $\lim\frac{u_n}{v_n}=l$：$0<l<\infty$ 同敛散；方向反了什么也不能说 |
| 等价替换的限制 | 把 $\frac1n$ 当 $x\to0$ 找主要部分；加减时不能直接替换，要用泰勒（$\frac1n-\sin\frac1n\sim\frac1{6n^3}$）；变号级数不能仅凭等价替换判断敛散 |
| 比值与根值 | 比值法要求从某项起 $u_n>0$，根值法要求 $u_n\ge0$；$\rho=\lim\frac{u_{n+1}}{u_n}$ 或 $\lim\sqrt[n]{u_n}$：$\rho<1$ 收敛，$\rho>1$ 发散，$\rho=1$ 失效（$\sum\frac1n$、$\sum\frac1{n^2}$）；阶乘用比值，$n$ 次方用根值 |
| 莱布尼茨判别法 | 交错级数 $\sum(-1)^{n-1}u_n$（$u_n>0$）：$u_n$ 单调减少且趋于 0 ⇒ 收敛，$\lvert R_n\rvert\le u_{n+1}$（误差不超过第一个舍去的项）；缺单调性时不能用 |
| 绝对收敛与条件收敛 | $\sum\lvert u_n\rvert$ 收敛 ⇒ $\sum u_n$ 收敛；绝对收敛可任意重排，条件收敛重排后和可能改变；比较判别得到的绝对值级数发散，原级数仍可能收敛 |
| 两个标杆 | $\sum\frac1n$ 发散（部分和 $S_{1000}\approx7.49$），$\sum\frac1{n^2}=\frac{\pi^2}6\approx1.6449$；交错调和级数的和是 $\ln2$ |
