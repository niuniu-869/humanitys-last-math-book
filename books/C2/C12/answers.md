## C.12 · 反常积分（答案）

### A 基础

**C12-01**
**答案：** 积分收敛，值为 $\frac13$。因为原函数为 $-\frac1{x+1}$，所以
$$\int_2^b\frac{\mathrm{d}x}{(x+1)^2}=\frac13-\frac1{b+1}\longrightarrow\frac13.$$

区分点：无穷上限要通过有限积分的极限处理，不能把无穷当作普通实数代入。

**C12-02**
**答案：** (D)。$I_p$ 收敛要求 $p<1$，$J_p$ 收敛要求 $p>1$，两个条件没有交集。

(A) 错在把瑕点处的条件用于无穷远；此时 $J_p$ 发散。(B) 错在把 $I_p$ 的发散推给 $J_p$；此时 $J_p$ 收敛。(C) 错在纳入边界，$p=1$ 时两个截断积分分别为 $-\ln\varepsilon$ 与 $\ln b$，都趋于 $+\infty$。(D) 正确。

区分点：同一个幂在零点和无穷远处的收敛条件方向相反，且都不含边界。

**C12-03**
**答案：** (C)。左侧截断积分是 $\ln\varepsilon\to-\infty$，右侧是 $\ln2-\ln\varepsilon\to+\infty$。

(A) 跨过了瑕点，不能直接代两个端点。(B) 只看右侧；左侧趋于负无穷，整个积分没有可指定的无穷值。(C) 正确，两侧没有各自收敛。(D) 只改一个点无法消除其附近的无界性。

区分点：必须检查瑕点的两侧，不能把两个发散量相加来定义反常积分。

**C12-04**
**答案：** $\Gamma(\frac92)=\frac{105}{16}\sqrt\pi$。由递推公式，
$$\Gamma\Big(\frac92\Big)=\frac72\cdot\frac52\cdot\frac32\cdot\frac12\Gamma\Big(\frac12\Big)=\frac{105}{16}\sqrt\pi.$$

区分点：每次把自变量减 1，并乘减后那个数，最后停在已知的 $\Gamma(\frac12)$。

### B 进阶

**C12-05**
**答案：** (C)。因为 $f/g=1/(\sqrt x\ln x)\to0$，所以 $L=0$。但令 $u=\ln x$，就有
$$\int_{\mathrm e}^{B}\frac{\mathrm{d}x}{x\ln x}=\ln\ln B\longrightarrow+\infty.$$

(A) 把「比一个发散函数小得多」当成了收敛的保证。(B) 把两者都趋于 0 误当成比值趋于 1。(C) 正确。(D) 颠倒了分子、分母的相对大小。

当比值极限为 0 时，比较判别法只保证「$\int g$ 收敛则 $\int f$ 收敛」；这里 $\int g$ 发散，不能倒推。比如 $1/x^2$ 与同一个 $g$ 的比值也趋于 0，但它的积分收敛。

区分点：先核对比较结论的方向；一个零比值本身不能决定较小函数的积分。

**C12-06**
**答案：** 新方案累计节省的支出为两种连续支出速率之差的积分，即

$$I=\int_1^{+\infty}\left(\frac1{\sqrt t}-\frac1{\sqrt{t+1}}\right)\mathrm{d}t=2(\sqrt2-1)\text{ 万元}.$$

先保留同一个有限上限 $b$：
$$\int_1^b\left(\frac1{\sqrt x}-\frac1{\sqrt{x+1}}\right)\mathrm{d}x=2(\sqrt b-\sqrt{b+1})+2(\sqrt2-1).$$
因为 $\sqrt b-\sqrt{b+1}=-1/(\sqrt b+\sqrt{b+1})\to0$，所以得到上述值。两个单独的反常积分都发散到 $+\infty$，不能用它们的差表示 $I$。
因此不能拆成两个反常积分相减。

区分点：先把连续支出速率相减再取极限；有限区间上的拆项合法，不代表取极限后仍能把每一项各自写成积分值。

**C12-07**
**答案：** 收敛。因为 $1-\cos x=2\sin^2(x/2)$，所以
$$\lim_{x\to0^+}\frac{1-\cos x}{x^2}=\frac12.$$
因此零点是可去的无定义点，补上值后，$[0,1]$ 上的积分有限。

当 $x\ge1$ 时，$0\le(1-\cos x)/x^2\le2/x^2$，而 $\int_1^{+\infty}2/x^2\,\mathrm{d}x$ 收敛，所以尾部也收敛。

区分点：分母在零点为零并不必然造成发散，要看分子是否同时消去；无穷远处则用上界比较。

**C12-08**
**答案：** $c=\frac12$。令 $t=x^2$，得到
$$\int_0^{+\infty}x^2\mathrm e^{-x^2}\,\mathrm{d}x=\frac12\Gamma\Big(\frac32\Big)=\frac{\sqrt\pi}4,\qquad
\int_0^{+\infty}\mathrm e^{-x^2}\,\mathrm{d}x=\frac12\Gamma\Big(\frac12\Big)=\frac{\sqrt\pi}2.$$
两项都收敛，且 $|(x^2-c)\mathrm e^{-x^2}|\le(x^2+|c|)\mathrm e^{-x^2}$，所以原积分绝对收敛，可以拆项。要求它为零，就是 $\sqrt\pi/4-c\sqrt\pi/2=0$，解得唯一的 $c=\frac12$。

区分点：被积函数变号时不能直接套非负函数的比较结论；先用绝对值控制，再通过两个积分反求系数。

**C12-09**
**答案：** 两个非负部分的积分都收敛，因此原积分收敛，且所给不等式成立。

因为 $0\le f_+\le|f|$、$0\le f_-\le|f|$，所以比较判别法保证它们的积分收敛。记两积分为 $A,B$，则 $A,B\ge0$。

在有限区间上，$f=f_+-f_-$、$|f|=f_++f_-$。各项积分都有有限极限，取极限后得到 $\int_1^{+\infty}f=A-B$ 与 $\int_1^{+\infty}|f|=A+B$。最后由 $|A-B|\le A+B$ 得到所需不等式。

区分点：比较判别法用于拆出的非负函数，不能直接用于变号的 $f$；相减前要先保证两项都收敛。

**C12-10**
**答案：** $-\frac12<a<1$。在 $\frac12$、$1$、$2$ 处分段，分别检查三个可能出问题的位置。

在零点附近，被积函数与 $x^{-1/2}$ 的比值趋于 1，所以总是可积。在 $x=1$ 的两侧，它与 $|x-1|^{-a}$ 的比值都趋于 $\frac12$，所以要求 $a<1$；$a\le0$ 时也符合这一条件。

在无穷远处，它与 $x^{-(a+3/2)}$ 的比值趋于 1，所以要求 $a+\frac32>1$。两条件取交集得到上述范围。$a=1$ 在内部点发散，$a=-\frac12$ 在无穷远处发散。

区分点：无穷远处还要把 $|x-1|^a$ 的幂计入；内部点的条件也不能因端点可积而省略。

### C 提高

**C12-11**
**答案：** (1) $1<a<2$；(2) $I(\frac32)=2\pi$。

在零点附近，$\ln(1+x)/x\to1$，所以被积函数与 $x^{1-a}$ 同阶，要求 $a<2$。当 $a=2$ 时，它与 $1/x$ 同阶，发散。

在无穷远处，若 $a>1$，取 $\delta=(a-1)/2>0$。因为 $\ln(1+x)/x^\delta\to0$，所以充分大的 $x$ 处，被积函数不超过 $x^{-(a+1)/2}$，其积分收敛。若 $a\le1$，则对 $x\ge\mathrm e$，$\ln(1+x)/x^a\ge1/x$，所以发散，特别是 $a=1$ 不能取。

求值时先在 $[\varepsilon,R]$ 上分部，取 $u=\ln(1+x)$、$v=-2/\sqrt x$。分部边界项确实消失：零点处

$$\frac{\ln(1+x)}{\sqrt x}=\frac{\ln(1+x)}x\sqrt x\longrightarrow1\cdot0=0,$$

无穷远处由洛必达法则

$$\lim_{x\to+\infty}\frac{\ln(1+x)}{\sqrt x}=\lim_{x\to+\infty}\frac{2\sqrt x}{1+x}=0.$$

余下积分 $1/(\sqrt x(1+x))$ 在零点附近与 $x^{-1/2}$ 等价，在无穷远与 $x^{-3/2}$ 等价，两端都收敛。因此
$$I\Big(\frac32\Big)=2\int_0^{+\infty}\frac{\mathrm{d}x}{\sqrt x(1+x)}.$$
再令 $x=t^2$，得到 $4\int_0^{+\infty}\mathrm{d}t/(1+t^2)=2\pi$。

区分点：零点处要保留对数消去一个幂的作用，无穷远处又不能把对数当作常数；分部之前须落实边界项的极限。

**C12-12**
**答案：** (1) 收敛当且仅当 $a>0$（$b$ 任意），或 $a=0$ 且 $b>1$；(2) $K(0,2)=1$，$K(1,-2)=5$。

令 $x=\mathrm e^{-t}$，先在截断区间上换元，再取极限，得到
$$K(a,b)=\int_0^{+\infty}\mathrm e^{-at}(1+t)^{-b}\,\mathrm{d}t.$$
$t=0$ 处的被积函数为 1，没有瑕点，剩下只需看无穷远。

若 $a>0$，则 $t^2\mathrm e^{-at}(1+t)^{-b}\to0$，由 $1/t^2$ 比较可知收敛。若 $a<0$，指数增长压过任意幂，被积函数趋于 $+\infty$，最终不小于 1，所以发散。若 $a=0$，则成为 $\int_0^{+\infty}(1+t)^{-b}\,\mathrm{d}t$，收敛恰好要求 $b>1$；$b=1$ 仍发散。

因此 $K(0,2)=[-(1+t)^{-1}]_0^{+\infty}=1$。另一值由展开和 $\Gamma$ 公式得到：
$$K(1,-2)=\int_0^{+\infty}(1+2t+t^2)\mathrm e^{-t}\,\mathrm{d}t=\Gamma(1)+2\Gamma(2)+\Gamma(3)=5.$$

区分点：$a=0$ 时指数衰减完全消失，要另用幂函数判别，不能把 $a>0$ 的结论延伸到边界。

### 章末混合练习

**C12-13**
**答案：** 两积分依次为 $0$、$\frac2{\mathrm e}$。用本章方法 1、3，结合 C.9 的有符号面积与 C.11 的分部积分。

因为 $(-x\mathrm e^{-x})'=(x-1)\mathrm e^{-x}$，且 $x\mathrm e^{-x}\to0$，所以第一个积分为 0。在 $x=1$ 处分开绝对值：
$$\int_0^1(1-x)\mathrm e^{-x}\,\mathrm{d}x=[x\mathrm e^{-x}]_0^1=\frac1{\mathrm e},\qquad
\int_1^{+\infty}(x-1)\mathrm e^{-x}\,\mathrm{d}x=\frac1{\mathrm e}.$$
于是第二个积分为 $2/\mathrm e$。第一个把正负面积相抵，第二个把两块面积都按正数相加。

区分点：积分外取绝对值保留了原先的抵消，积分内取绝对值则要先按变号点拆区间。

**C12-14**
**答案：** $F(t)=\dfrac{\ln t+1}{t}$，$F'(t)=-\dfrac{\ln t}{t^2}$，所求极限为 $1$。用本章方法 1，结合 C.11 的分部积分与 C.10 的变限积分求导。

取 $u=\ln x$、$v=-1/x$，先积到 $R$：
$$\int_t^R\frac{\ln x}{x^2}\,\mathrm{d}x=\frac{\ln t+1}{t}-\frac{\ln R+1}{R}.$$
因为后项趋于 0，得到 $F(t)$。再求导得到 $F'(t)$，负号也与 $F(t)=F(1)-\int_1^t(\ln x)/x^2\,\mathrm{d}x$ 一致。最后 $tF(t)/\ln t=1+1/\ln t\to1$。

区分点：下限增大意味着删去一段积分，求导带负号；求尾积分时还要验证无穷远的边界项消失。

**C12-15**
**答案：** 仅当 $a=0$ 时收敛，值为 $\frac\pi2$；对称截断极限对所有实数 $a$ 都是 $\frac\pi2$，不能给出正确的参数条件。用本章方法 1、3，结合 C.11 的奇偶性与三角换元。

记被积函数为 $h_a(x)$。因为 $\lim_{x\to+\infty}xh_a(x)=a$，所以 $a\ne0$ 时它最终符号固定，且 $|h_a(x)|$ 与 $|a|/x$ 同阶，右半积分就发散。

当 $a=0$ 时，$h_0$ 在两端都按 $1/|x|^3$ 的量级绝对可积，可以拆出奇函数项 $x/(1+x^2)^2$，它的积分为 0。剩下令 $x=\tan t$：
$$\int_{-\infty}^{+\infty}\frac{\mathrm{d}x}{(1+x^2)^2}=\int_{-\pi/2}^{\pi/2}\cos^2t\,\mathrm{d}t=\frac\pi2.$$
但在任意有限的对称区间上，两项 $ax^3$ 与 $x$ 对应的奇函数积分都为 0，所以对称截断看不出 $a\ne0$ 时两侧的发散。

区分点：奇偶性可以化简每个有限的对称积分，却不能替代整条实轴上两个单侧积分的收敛检验。
