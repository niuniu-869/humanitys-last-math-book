## C.17 · 一阶微分方程（速记）

| 提示 | 内容 |
|---|---|
| 解、通解、特解 | 代入后成为恒等式就是解；一阶方程的通解带一个任意常数；用初值条件定常数得特解 |
| 斜率场 | 在点 $(x,y)$ 画斜率 $f(x,y)$ 的短线，解曲线与短线相切；满足唯一性条件处解曲线互不相交 |
| 欧拉折线 | $y_{k+1}=y_k+h\,f(x_k,y_k)$；梯度下降 $\theta_{k+1}=\theta_k-\eta L'(\theta_k)$ 就是 $\theta'=-L'(\theta)$ 的欧拉折线；对 $L=2\theta^2$，$\eta>0.5$ 时发散 |
| 分离变量 | $y'=f(x)g(y)$ ⇒ $\int\frac{\mathrm dy}{g(y)}=\int f(x)\,\mathrm dx$，只在一边加常数；补回 $g(c)=0$ 的常数解 |
| 指数衰减 | 在指数衰减模型 $y'=-ky$ 下 ⇒ $y=y_0e^{-kt}$，半衰期 $\frac{\ln2}k$ 与 $y_0$ 无关；冷却：温差满足同一方程 |
| logistic | $y'=ry\left(1-\frac yK\right)$，部分分式积分，S 形；$y=\frac K2$ 时增长最快 |
| 齐次方程 | $y'=\varphi\left(\frac yx\right)$：令 $u=\frac yx$，$y'=u+xu'$（不是 $u'$），化为 $xu'=\varphi(u)-u$；信号：分子分母各项同次 |
| 一阶线性方程 | $y'+P(x)y=Q(x)$，$y'$ 系数先化成 1 |
| 积分因子 | $\mu=e^{\int P\,\mathrm dx}$，$(\mu y)'=\mu Q$，$y=\frac1\mu\left(\int\mu Q\,\mathrm dx+C\right)$ |
| 常数变易法 | 先解 $y'+Py=0$ 得 $Ce^{-\int P}$，再令 $C\to C(x)$ 代回；被变易的常数就是 $\mu y$ |
| 解的结构 | 线性方程的通解 = 一个特解 + 对应齐次线性方程的通解；特解常是稳态，齐次部分记着离稳态多远 |
| 伯努利方程 | $y'+Py=Qy^n$（$n\ne0,1$）：令 $z=y^{1-n}$，得 $z'+(1-n)Pz=(1-n)Q$；$n>0$ 时补 $y\equiv0$ |
| 其他换元 | 成团出现的量（如 $u=x+y$）当新未知函数；对 $y$ 不线性时试把 $x$ 看成 $y$ 的函数 |
| 选方法的顺序 | 分离 → 齐次 → 线性 → 伯努利 → 成团换元 → $x$、$y$ 对调 |
