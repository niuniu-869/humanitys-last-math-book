## K3.5 · 动态规划（二）：序列上的动态规划

git 比较两个版本的文件，显示哪几行被删、哪几行被加；论文查重软件找两篇文章里共同的片段；输入法在你打错字时猜你想打哪个词；语音识别系统给一句识别结果打分，看它和标准文字差几个词。这些工作的核心都是比较两个序列，找出它们最大的相同部分，或者数出把一个改成另一个至少要几步。

这类问题在生物学和通信里都出现过。蛋白质是氨基酸排成的长串，两种蛋白质越像，来源就可能越近。1965 年，苏联数学家列文斯坦（Levenshtein）在研究纠错码时，把「把一个字符串改成另一个，最少要几次单字符修改」定义为两个串的距离。1970 年，尼德曼（Needleman）和翁施（Wunsch）用动态规划做蛋白质序列比对：把问题拆成子问题，把每一步的结果填进一张表。

K3.4 的状态是「前 $i$ 件物品、容量 $w$」这样的一对数，转移靠「最后一步有几种做法，取最优」。本章把同一套四要素（状态、转移、边界、填表顺序）搬到序列上。第 1 节只有一个序列，状态是「以第 $i$ 个数结尾」；第 2、3 节有两个序列，状态是「各取前几个」；第 4 节讲表填完以后怎样读出方案本身；第 5 节把状态换成区间；第 6 节总结拿到新题时怎样设计状态。

本章用的伪代码和 K3.1 一致：缩进表示层次，赋值写「←」，数组下标从 1 开始。

### 1. 一串数里，最长的上升子序列有多长？

从数组 $a$ 里按原来的先后顺序挑出若干个数，不要求相邻，得到的叫**子序列**。如果挑出的数一个比一个大（严格增大），就叫**上升子序列**。老朋友①是 $[5,2,8,1,9,3]$，$5,8,9$ 是它的上升子序列，$2,3$ 也是，$8,1$ 不是。问题是：最长的上升子序列有多长？（下面都设数组非空。）

先沿用 K3.4 的习惯，把状态设成「前 $i$ 个数里的答案」，记作 $f(i)$。对老朋友①，$f(1)=1$（只有 5），$f(2)=1$，$f(3)=2$（$5,8$ 或 $2,8$），$f(4)=2$。现在要算 $f(5)$，新来的数是 9。9 比前面所有数都大，能接在任何一个上升子序列后面，所以 $f(5)=3$。如果新来的是 3 呢？它能不能接在某个长度为 2 的子序列后面，要看那个子序列的**最后一个数**是否小于 3，而 $f(4)=2$ 这个数里没有记下结尾是谁。这说明状态里缺了关键信息。

补救的办法是把结尾钉死。

**方法 1（以谁结尾设状态）**

1. 状态：$d[i]$ 表示以第 $i$ 个数 $a[i]$ **结尾**的最长上升子序列的长度。
2. 转移：这个子序列的倒数第二个数要么不存在，要么是某个 $a[j]$（$j<i$，且 $a[j]<a[i]$），去掉 $a[i]$ 后剩下的是以 $a[j]$ 结尾的上升子序列，它的长度不会超过 $d[j]$（否则与 $d[j]$ 的定义矛盾）；反过来，取一条长度恰为 $d[j]$、以 $a[j]$ 结尾的上升子序列，接上 $a[i]$ 仍然上升，长度是 $d[j]+1$。所以最长的就是 $d[j]+1$，

$$d[i]=1+\max\{\,d[j]\mid j<i,\ a[j]<a[i]\,\},$$

花括号为空时，最大值取 0，$d[i]=1$。

3. 边界：不需要单独写，$i=1$ 时花括号就是空的。
4. 顺序：$i$ 从小到大，算 $d[i]$ 时用到的 $d[j]$ 都已填好。
5. 答案：$\max_i d[i]$，不是 $d[n]$，因为最长的子序列不一定以最后一个数结尾。

```text
LIS(a, n):
  for i ← 1 to n
    d[i] ← 1
    for j ← 1 to i−1
      if a[j] < a[i] and d[j]+1 > d[i]
        d[i] ← d[j]+1
  return max(d[1..n])
```

**例 1**　开头 $f(i)$ 那条路卡在「不知道结尾是谁」，现在状态改成 $d[i]$，还是用老朋友① $a=[5,2,8,1,9,3]$，把它从头算通。

按方法 1 逐项算，每一项把前面比它小的数找出来：

| $i$ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| $a[i]$ | 5 | 2 | 8 | 1 | 9 | 3 |
| 前面比它小的 $d[j]$ | 无 | 无 | 1, 1 | 无 | 1, 1, 2, 1 | 1, 1 |
| $d[i]$ | 1 | 1 | 2 | 1 | 3 | 2 |

例如 $d[5]$：9 前面的 5、2、8、1 都比它小，对应的 $d$ 是 1、1、2、1，最大是 2，所以 $d[5]=3$。最大的 $d[i]$ 是 3，最长上升子序列长度为 3，例如 $5,8,9$ 或 $2,8,9$。

![对有前驱的数，向一个最佳前驱连弧，并列时只画其中一个：$d[5]=3$ 来自 8，8 来自 5 或 2；结尾为 9 的弧链就是一个最长上升子序列；数下方标 $d[i]$](fig/K35-n1.pdf){width=80%}

> 对 $[2,6,3,4,1,5]$ 求最长上升子序列的长度。
>
> 答案：$d[4]$：4 前面比它小的是 2、3，$d$ 为 1、2，所以 $d[4]=3$；$d[6]$：5 前面比它小的是 2、3、4、1，最大的 $d$ 是 3，所以 $d[6]=4$。整列 $d=[1,2,2,3,1,4]$，答案是 4，例如 $2,3,4,5$。

**例 2**　方法不变，只是这次数组里有重复的数：$a=[3,1,4,1,5,9,2,6]$。转移里的条件是 $a[j]<a[i]$，相等的数不算「更大」，读者容易顺手写成 $\le$，下面看这一点怎样影响结果。

$d[1]=1$，$d[2]=1$。$d[3]$：4 前面比它小的有 3 和 1，$d$ 为 1、1，所以 $d[3]=2$。$d[4]$：第二个 1 前面没有比它小的（第一个 1 与它相等，不算），$d[4]=1$。

$d[5]$：5 前面比它小的是 3、1、4、1，$d$ 为 1、1、2、1，所以 $d[5]=3$。$d[6]$：9 前面都比它小，最大 $d$ 是 3，所以 $d[6]=4$。

$d[7]$：2 前面比它小的是两个 1，$d[7]=2$。$d[8]$：6 前面比它小的是 3、1、4、1、5、2，最大 $d$ 是 $d[5]=3$，所以 $d[8]=4$。

$$d=[1,1,2,1,3,4,2,4],\qquad \max d=4 .$$

长度为 4 的上升子序列有 $3,4,5,9$，也有 $3,4,5,6$。这道题学到的是：严格上升与不降要在转移的比较符号里区分，改成 $a[j]\le a[i]$ 就是求最长不降子序列。

**计数。** 内层比较的总次数是 $0+1+\cdots+(n-1)=n(n-1)/2$，所以时间是 $\Theta(n^2)$，空间是 $\Theta(n)$。

合上书，写出 $d[i]$ 的定义和转移式，并说明为什么答案是 $\max d[i]$，而状态「前 $i$ 个数里的最长长度」缺少什么信息。

这一节的数据只有一个序列，状态里一个下标就够了。文本比对、查重面对的是两个序列，要找的是它们共有的那一部分，一个下标不够，下一节就从这里接着走。

### 2. 两段文本最长的公共子序列是什么？

上一节的子序列这个词现在用在两个序列上。两个序列 $X=x_1x_2\cdots x_m$ 和 $Y=y_1y_2\cdots y_n$ 的**公共子序列**，是既为 $X$ 的子序列、又为 $Y$ 的子序列的序列。最长的一个叫**最长公共子序列**（LCS）。比如 $X=\text{ACGTTA}$、$Y=\text{AGTCA}$（可以想成两段很短的基因片段），AGTA 就是它们的一个公共子序列：在 $X$ 里取第 1、3、4、6 个字符，在 $Y$ 里取第 1、2、3、5 个字符。

现在有两个序列，状态也要同时描述两个序列。K3.4 的背包用「前 $i$ 件、容量 $w$」两个数，这里的类比是「$X$ 取前 $i$ 个字符，$Y$ 取前 $j$ 个字符」：

$$c[i][j]=\text{“}x_1\cdots x_i\text{ 与 }y_1\cdots y_j\text{ 的最长公共子序列的长度”} .$$

要的答案是 $c[m][n]$。边界很直接：有一个串是空串，公共子序列只能是空的，$c[i][0]=c[0][j]=0$。

转移看两个串的**最后一个字符** $x_i$ 和 $y_j$。

**定理**　对 $1\le i\le m$，$1\le j\le n$，

$$c[i][j]=\begin{cases}c[i-1][j-1]+1,&x_i=y_j,\\ \max\{c[i-1][j],\ c[i][j-1]\},&x_i\ne y_j.\end{cases}$$

先在例子上看。$X=\text{ACGTTA}$、$Y=\text{AGTCA}$，$i=6,j=5$ 时两个末字符都是 A，相等。公共子序列末尾配上这一对 A，前面剩下的部分是 ACGTT 与 AGTC 的公共子序列，所以 $c[6][5]=c[5][4]+1$。再看 $i=5,j=4$，末字符是 T 和 C，不等；这时 T 和 C 不可能同时被用上，因为它们都在各自串的末尾，同时用上就必须互相配对，而 T 和 C 配不上。所以要么放弃 T（看 ACGT 与 AGTC），要么放弃 C（看 ACGTT 与 AGT），取较大的。

下面是一般情形的证明，分两种情况。证明里说一个公共子序列 $Z$ 的字符「配在」$X$ 的某个位置，意思是：$Z$ 的各字符在 $X$ 里各对应一个位置，位置从左到右递增（$Y$ 里同理）；同一个 $Z$ 可能有几种配法，证明里只用到「最后一个字符配在哪里」。

**证明**　记 $L$ 为 $x_1\cdots x_i$ 与 $y_1\cdots y_j$ 的最长公共子序列 $Z$ 的长度。

情形一，$x_i=y_j$。

1. 先证 $L\ge c[i-1][j-1]+1$：取前缀的一个最长公共子序列，在末尾接上这个相同的字符 $x_i=y_j$，仍是公共子序列。
2. 再证 $L\le c[i-1][j-1]+1$：如果 $Z$ 的最后一个字符既没有配在 $x_i$ 上，也没有配在 $y_j$ 上，就在 $Z$ 末尾接上 $x_i$，得到更长的公共子序列，与 $Z$ 最长矛盾。所以它至少配在其中一个上，比如配在 $x_i$ 上，这时它等于 $x_i=y_j$。它在 $Y$ 里原来配在某个 $y_{j'}$（$j'\le j$），而它是 $Z$ 的最后一个字符，前面各字符在 $Y$ 里的位置都比 $j'$ 小，改配 $y_j$ 不会破坏先后顺序。于是 $Z$ 的最后一个字符同时配在 $x_i$ 与 $y_j$ 上，去掉它，剩下 $L-1$ 个字符是 $x_1\cdots x_{i-1}$ 与 $y_1\cdots y_{j-1}$ 的公共子序列，所以 $L-1\le c[i-1][j-1]$。

情形二，$x_i\ne y_j$。

1. $Z$ 不可能同时用到 $x_i$ 和 $y_j$：$x_i$ 是 $X$ 前缀的最后一个字符，用到它就必然是 $Z$ 的最后一个字符；$y_j$ 同理。同时用到，两个字符都是 $Z$ 的最后一个字符，就得 $x_i=y_j$，矛盾。
2. 没用 $x_i$ 时，$Z$ 是 $x_1\cdots x_{i-1}$ 与 $y_1\cdots y_j$ 的公共子序列，$L\le c[i-1][j]$；没用 $y_j$ 时 $L\le c[i][j-1]$。所以 $L\le\max\{c[i-1][j],c[i][j-1]\}$。反过来，$x_1\cdots x_{i-1}$ 与 $y_1\cdots y_j$ 的公共子序列，也是 $x_1\cdots x_i$ 与 $y_1\cdots y_j$ 的公共子序列，所以 $c[i-1][j]\le L$，同理 $c[i][j-1]\le L$，于是 $\max\{c[i-1][j],c[i][j-1]\}\le L$。两个方向合起来，$L$ 等于这个最大值。$\square$

这个证明只用到「末字符」这一个观察，是后面编辑距离的模板。

定理的两个分支各自都不能省。末字符不等时只看左上角是错的：$X=\text{AB}$、$Y=\text{BA}$ 的末字符 B 与 A 不等，左上角 $c[1][1]$ 是 A 与 B 的值 0，但 $c[2][2]=1$（取 A 或取 B 都行）。另一种自然的做法是从左到右扫描，每遇到能配上的字符就先配上。$X=\text{ABC}$、$Y=\text{BCA}$ 里，先把 $X$ 的 A 配到 $Y$ 的 A 上以后再也配不上别的字符，得到长度 1，而 BC 的长度是 2。贪心在这里和 K3.4 开头的找零一样会出错，所以要靠填表比较所有的可能。

**方法 2（两个序列的前缀设状态）**

1. 状态 $c[i][j]$：$X$ 的前 $i$ 个与 $Y$ 的前 $j$ 个。边界 $c[i][0]=c[0][j]=0$。
2. 转移：末字符相等，左上角加 1；不等，取上方和左方的较大者。
3. 顺序：按行从上到下、每行从左到右填，每格用到的左上、上、左三格都已填好。答案在右下角。

![第 $(i,j)$ 格只依赖左上、上、左三格：实线箭头（末字符相等时用）来自左上角并加 1，虚线箭头（不等时用）来自上方和左方，取较大者；空心圆是正在算的格](fig/K35-n2.pdf){width=55%}

> 求 $X=\text{BCDA}$、$Y=\text{ABDCA}$ 的 LCS 长度。
>
> 答案：末字符都是 A，相等，$c[4][5]=c[3][4]+1$。$c[3][4]$ 是 BCD 与 ABDC 的值，末字符 D 与 C 不等，取 $\max\{c[2][4],c[3][3]\}=\max\{1,2\}=2$（BD）。所以 $c[4][5]=3$，例如 BDA。

**计数。** 表有 $(m+1)(n+1)$ 格，每格常数步，时间 $\Theta(mn)$。

**例 4**　回到老朋友①，把第 1 节的问题改写成 LCS，看两种做法是否一致。这里没有新方法，只是把例 1 换一个角度重做。

把 $a=[5,2,8,1,9,3]$ 排好序得 $b=[1,2,3,5,8,9]$。$a$ 的任何上升子序列，因为 $b$ 是从小到大排的，数又互不相同，所以这些数在 $b$ 里也按同样的先后出现，它就是 $a$ 与 $b$ 的公共子序列。反过来，$a$ 与 $b$ 的公共子序列在 $b$ 里是上升排列，所以在 $a$ 里也是上升的。因此

$$\text{LIS}(a)=\text{LCS}(a,\ \text{把 }a\text{ 排好序的数组})\qquad(a\text{ 中各数互不相同时}).$$

填出 $6\times6$ 的表，右下角是 3，和例 1 一致。这个换法没有更快（同样是 $\Theta(n^2)$），价值是说明两类问题是同一类。$a$ 里有重复的数时（例 2），公共子序列在 $b$ 里只能保证不降，所以这个换法求出的是最长不降子序列；要严格上升，就把 $b$ 里相等的值只留一个，$a$ 不动。

合上书，写出 $c[i][j]$ 的两种转移，并解释为什么「末字符不等」时可以放心地丢掉一个字符。

LCS 只能保留字符，两个词差一个字母时，它只告诉我们共有几个字符，没有告诉我们要怎样改。拼写纠错要的是把一个词改成另一个词的最少步数，这是下一节的问题。

### 3. 一个词最少改几步，能变成另一个词？

先看最小的情形：cat 变 cut，把 a 换成 u，一步。LCS 看不到这种「换一个字母」的动作，所以拼写纠错要的是另一种距离：对一个串每次可以做三种单字符操作之一，

- **插入**一个字符；
- **删除**一个字符；
- **替换**一个字符为另一个字符，

把 $X$ 变成 $Y$ 最少要几次？这叫**编辑距离**（也叫列文斯坦距离）。

状态沿用方法 2：$e[i][j]$ 是把 $x_1\cdots x_i$ 变成 $y_1\cdots y_j$ 的最少操作数，答案是 $e[m][n]$。边界：变成空串只能全删，从空串变出 $y_1\cdots y_j$ 只能全插，$e[i][0]=i$，$e[0][j]=j$。

转移看**最后一步**对末字符做了什么。把一个最优的修改方案，按两个串的字符怎样对上来整理：最右端没有对上的 $x_i$ 只能被删除，没有对上的 $y_j$ 只能是插入的，$x_i$ 与 $y_j$ 对上时只能保留或替换。这样整理不会增加操作数：多余的「插入后又删除」「反复替换同一个字符」都可以消去。所以把 $x_1\cdots x_i$ 变成 $y_1\cdots y_j$，末尾必然是下面三种情形之一，而且每种情形里，前面那部分必须是对应子问题的最优方案：如果前面不是最优，换成更少的方案再接上同一步，总数会更少，与整体最优矛盾。

1. 删掉 $x_i$：前面 $x_1\cdots x_{i-1}$ 已变成 $y_1\cdots y_j$，代价 $e[i-1][j]+1$。
2. 在末尾插入 $y_j$：前面 $x_1\cdots x_i$ 已变成 $y_1\cdots y_{j-1}$，代价 $e[i][j-1]+1$。
3. 让 $x_i$ 对应 $y_j$：前面 $x_1\cdots x_{i-1}$ 已变成 $y_1\cdots y_{j-1}$，再加上末字符处理：相等不用动，不等替换一次，代价 $e[i-1][j-1]+[x_i\ne y_j]$，其中方括号在条件成立时为 1，否则为 0。

所以对 $1\le i\le m$，$1\le j\le n$，

$$e[i][j]=\min\{\,e[i-1][j]+1,\ \ e[i][j-1]+1,\ \ e[i-1][j-1]+[x_i\ne y_j]\,\}.$$

和 LCS 比：依赖的还是左上、上、左三格，但这次三格总是都要参与，因为三种操作在任何位置都可以做。

**方法 3（编辑距离）**　状态 $e[i][j]$；第 0 行 $e[0][j]=j$，第 0 列 $e[i][0]=i$；每格取三项的最小值；答案在右下角。

| e | 5 | 5 | 4 | 3 | 2 | 2 | 3 | 4 |

取两格验算。第 1 行（k）第 1 列（s）：$x_1\ne y_1$，三项为 $e[0][1]+1=2$、$e[1][0]+1=2$、$e[0][0]+1=1$，最小 1，就是把 k 替换成 s。第 6 行（n）第 6 列（n）：末字符相等，三项为 $e[5][6]+1=4$、$e[6][5]+1=4$、$e[5][5]+0=2$，最小 2。

**例 6**　这是回到章首的问题。规则和例 5 完全一样，只是「字符」换成「词」。语音识别系统给识别结果打分时，把一句话看成词的序列，用词级的编辑距离，除以标准文本的词数，叫词错误率。标准文本为 the cat sat on the mat（6 个词），识别结果为 the cat sat the mat now，求它们的词错误率。

把每个词当成一个「字符」，用同样的表。填表（行是标准文本的前缀，列是识别结果的前缀）得 $e[6][6]=2$。具体改法是删去 on，在末尾加上 now。词错误率是 $2/6=1/3$。章首说的“识别结果和标准文字差几个词”，答案就是这个 $2$。

**对照：只允许插入和删除。** 编辑距离允许替换，LCS 只相当于「插入和删除」。只用这两种操作，保留 LCS 里的字符，其余全删、全插，所以最少操作数是 $m+n-2\cdot\mathrm{LCS}$。kitten 与 sitting 的 LCS 是 ittn，长度 4，只用插删要 $6+7-8=5$ 次，比允许替换的 3 次多。两种距离的状态相同、转移的条件不同，差别就在「不等时能不能用一步替换处理」。

### 4. 表填完了，怎样读出最优方案本身？

前三节填出的是最优**值**。拼写纠错要给出怎么改，文本比对要列出哪些字符是共同的，所以还要读出**方案**。方案不需要重新求解，只需要沿着填表时「是谁让我得到这个值」往回走。

**方法 4（回溯）**

1. 从右下角 $(m,n)$ 出发，看当前格的值是由哪一格得来的，往那一格走；
2. 每走一步，记下这一步对应的字符或操作；
3. 走到第 0 行或第 0 列为止，把记下的内容倒过来读。

对 LCS：这就是定理的两个分支倒过来读。若 $x_i=y_j$，值来自左上角加 1，走左上并收下这个字符；否则值来自上方和左方的较大者，往值较大的那一格走（两者相等时随便选一个）。对编辑距离：把三项 $e[i-1][j]+1$、$e[i][j-1]+1$、$e[i-1][j-1]+[x_i\ne y_j]$ 重新算一遍，看哪一项等于当前格的值，就是哪种操作；有几项同时等于当前值时，任选一项都能得到一个最优方案；走左上项时，末字符相等记「保留」，不等记「替换」。

**例 7**　例 3 的表已经填好，现在不再填新格，只从右下角往回走，读出 $X=\text{ACGTTA}$ 与 $Y=\text{AGTCA}$ 的一个 LCS。

- $(6,5)$：$x_6=y_5=\text{A}$，收下 A，走到 $(5,4)$。
- $(5,4)$：T 与 C 不等，上方 $c[4][4]=3$，左方 $c[5][3]=3$，相等；选上方，走到 $(4,4)$。
- $(4,4)$：T 与 C 不等，上方 $c[3][4]=2$，左方 $c[4][3]=3$，往左走到 $(4,3)$。
- $(4,3)$：$x_4=y_3=\text{T}$，收下 T，走到 $(3,2)$。
- $(3,2)$：$x_3=y_2=\text{G}$，收下 G，走到 $(2,1)$。
- $(2,1)$：C 与 A 不等，上方 $c[1][1]=1$，左方 $c[2][0]=0$，往上走到 $(1,1)$。
- $(1,1)$：$x_1=y_1=\text{A}$，收下 A，走到 $(0,0)$，结束。

收下的字符依次是 A、T、G、A，倒过来读得到 **AGTA**，长度 4，与 $c[6][5]=4$ 一致。

![LCS 表中的回溯路径：粗框格是路径，斜线段上的格收下一个字符（A、T、G、A，倒读为 AGTA），竖线段和横线段是舍弃一个字符；$(5,4)$ 处上方和左方相等，选哪边都可以](fig/K35-n4.pdf){width=70%}

最长公共子序列一般不止一个，并列时选不同方向可能读出不同的串。例 7 的两个串恰好只有 AGTA 一个，所以在 $(5,4)$ 处选上方还是左方，最后读出的是同一个串。

**例 8**　用例 5 的表读出 kitten 变成 sitting 的编辑方案。和例 7 的不同是，每一步要把三项都算一遍，才能判断是哪种操作。

从 $(6,7)$ 出发：$e=3$。上方 $e[5][7]+1=5$，左方 $e[6][6]+1=3$，左上 $e[5][6]+[\text{n}\ne\text{g}]=3+1=4$。最小的是左方，对应「插入 g」。走到 $(6,6)$。

$(6,6)$：$e=2$，$x_6=y_6=\text{n}$，左上 $e[5][5]=2$，相等，保留 n，走到 $(5,5)$。

$(5,5)$：$e=2$，e 与 i 不等，左上 $e[4][4]+1=2$，替换 e 为 i，走到 $(4,4)$。之后 $(4,4),(3,3),(2,2)$ 的末字符都相等（t、t、i），保留，走到 $(1,1)$。

$(1,1)$：$e=1$，k 与 s 不等，替换 k 为 s，走到 $(0,0)$。

倒过来读：k→s，保留 i、t、t，e→i，保留 n，插入 g，共 3 次。

> 用例 3 随堂题里 $X=\text{BCDA}$、$Y=\text{ABDCA}$ 的表，读出一个长度为 3 的公共子序列。
>
> 答案：$(4,5)$ 末字符都是 A，收下 A，走到 $(3,4)$；D 与 C 不等，上方 $c[2][4]=1$，左方 $c[3][3]=2$，往左到 $(3,3)$；两个末字符都是 D，收下 D，走到 $(2,2)$；C 与 B 不等，往值较大的上方走到 $(1,2)$；B 与 B 相等，收下 B。倒读得 BDA。

**空间的代价。** 只要最优值时，每一行只依赖上一行，用两行滚动就行（K3.4.6 对背包做过类似的事），沿较短的那个串滚动，空间降到 $\Theta(\min(m,n))$。要回溯，就得保留整张表（或记下每格的来向），空间是 $\Theta(mn)$。这是想要方案时要付的代价。

LIS 的回溯更简单：填 $d[i]$ 时顺便记下最佳前驱 $p[i]$，最后从 $d$ 最大的位置出发沿 $p$ 倒走。老朋友①里，$d[5]=3$ 的前驱是 8，8 的前驱是 5（也可以是 2），走出 $5,8,9$。

合上书，说出回溯时每一步依据什么判断往哪走，以及为什么只要最优值时可以省空间，要方案时不行。

前面四节的状态都是前缀或者结尾，最后一步总是在处理末尾。有些问题的最后一步却要把一段从中间切开，下一节的矩阵连乘就是这样。

### 5. 一串矩阵连乘，先乘哪两个最省？

这一节的状态是一段连续的**区间**，和前缀、「以谁结尾」都不同。

三个矩阵 $A$（$10\times30$）、$B$（$30\times5$）、$C$（$5\times60$）要连乘。乘法满足结合律，$(AB)C$ 与 $A(BC)$ 的结果相同，但 $p\times q$ 的矩阵乘 $q\times r$ 的矩阵，按定义要做 $pqr$ 次数的乘法（L.3），所以两种次序的工作量不同：

$$(AB)C:\ 10\cdot30\cdot5+10\cdot5\cdot60=1500+3000=4500,$$

$$A(BC):\ 30\cdot5\cdot60+10\cdot30\cdot60=9000+18000=27000.$$

差了 6 倍。矩阵多了以后，括号的方式有指数多种，一个个试不可能。

设有 $A_1,\dots,A_n$，$A_k$ 是 $p_{k-1}\times p_k$ 矩阵。状态是区间：$M[i][j]$ 表示算出 $A_i\cdots A_j$ 所需的最少乘法次数。看**最后一次乘法**：任何一种加括号的方式，最外层都是把左右两段的结果相乘，所以最后一次乘法一定存在。它把 $A_i\cdots A_k$ 与 $A_{k+1}\cdots A_j$ 两段各自的结果相乘，$k$ 在 $i$ 到 $j-1$ 之间。两段结果的形状是 $p_{i-1}\times p_k$ 和 $p_k\times p_j$，最后一次乘法花 $p_{i-1}p_kp_j$。状态只对 $1\le i\le j\le n$ 定义。固定分割点 $k$ 以后，两段各自的括号方式互不影响，所以两段都取最少的才能使总数最少（如果左段有更少的方案，换进去总数会变小，与最优矛盾）。于是

$$M[i][j]=\min_{i\le k<j}\{\,M[i][k]+M[k+1][j]+p_{i-1}p_kp_j\,\},\qquad M[i][i]=0.$$

填表顺序要小心：$M[i][j]$ 用到的是更短的区间，所以按区间长度从小到大填，不是按行从上到下。

**方法 5（区间动态规划）**　状态是区间 $[i,j]$；转移枚举最后一次分割点 $k$；按区间长度从短到长填表。

**例 9**　上面三个矩阵只有两种括号方式，一眼就能比。现在换四个矩阵，维度为 $p=(5,10,3,12,5)$，即 $A_1$ 是 $5\times10$，$A_2$ 是 $10\times3$，$A_3$ 是 $3\times12$，$A_4$ 是 $12\times5$，括号方式有五种，要靠区间表来比。求最少的乘法次数。

长度 2 的区间直接乘：

$$M[1][2]=5\cdot10\cdot3=150,\quad M[2][3]=10\cdot3\cdot12=360,\quad M[3][4]=3\cdot12\cdot5=180.$$

长度 3 的区间枚举分割点。$M[1][3]$：$k=1$ 时 $0+360+5\cdot10\cdot12=960$，$k=2$ 时 $150+0+5\cdot3\cdot12=330$，取 330。$M[2][4]$：$k=2$ 时 $0+180+10\cdot3\cdot5=330$，$k=3$ 时 $360+0+10\cdot12\cdot5=960$，取 330。

长度 4：

| 分割点 $k$ | 计算 | 总数 |
|---|---|---|
| 1 | $M[1][1]+M[2][4]+5\cdot10\cdot5=0+330+250$ | 580 |
| 2 | $M[1][2]+M[3][4]+5\cdot3\cdot5=150+180+75$ | 405 |
| 3 | $M[1][3]+M[4][4]+5\cdot12\cdot5=330+0+300$ | 630 |

最少是 405，在 $k=2$ 处取到，也就是 $(A_1A_2)(A_3A_4)$。

回溯和第 4 节一样：记下每个区间取到最小值的 $k$，从 $[1,n]$ 出发递归地展开，得到括号方案。

> 三个矩阵的维度 $p=(2,3,4,5)$，求最少的乘法次数。
>
> 答案：$M[1][2]=2\cdot3\cdot4=24$，$M[2][3]=3\cdot4\cdot5=60$。$M[1][3]$：$k=1$ 时 $0+60+2\cdot3\cdot5=90$，$k=2$ 时 $24+0+2\cdot4\cdot5=64$，取 64，即 $(A_1A_2)A_3$。

**计数。** 区间有 $\Theta(n^2)$ 个，每个枚举最多 $n$ 个分割点，时间 $\Theta(n^3)$，空间 $\Theta(n^2)$。

到这里已经有四种设状态的办法，各有各的适用处。遇到一道没见过的题，该怎么选，是最后一节的问题。

### 6. 拿到一道没见过的题，怎样设计状态？

四种问题的状态各不相同：LIS 是「以谁结尾」，LCS 与编辑距离是「两串各取前几个」，矩阵连乘是「区间」，背包是「前几件加容量」。拿到新题时，可以问自己三个问题。

**方法 6（设计状态的三问）**

1. 最后一步是什么？问最后一个元素怎么处理，或者最后一次操作是什么。
2. 要记住什么？为了判断这一步合不合法、值多少，需要知道前面哪些信息，这些信息就是状态里的下标。
3. 规模怎样缩小？去掉最后一步以后，剩下的是同一个问题的更小版本，它由哪几个数（前缀长度、区间端点、剩余容量）刻画。

写出状态和转移以后，再检查：转移用到的状态都在填表顺序里排在前面吗；边界覆盖了最小的情形吗；答案在表的哪个位置。

**对照：「前 $i$ 个」和「以 $i$ 结尾」。** 两种设法都很常见，什么时候用哪一个，取决于第 2 问：新来的元素能不能接上去，需不需要知道上一个选了谁。LIS 要比较前一个数的大小，必须钉死结尾；下面两题一个钉结尾，一个不需要。

**例 10**　求数组 $[-2,1,-3,4,-1,2,1,-5,4]$ 的**连续**子段的最大和。子段必须连续，下一个数能不能接上取决于上一段是不是正好结束在前一位，这和例 1 的困难相同，所以状态也钉结尾。

用第 1 问：最后一步是第 $i$ 个数要不要接在前一段后面。设 $g[i]$ 是以第 $i$ 个数结尾的连续子段的最大和，先有 $g[1]=a[1]$。$i\ge2$ 时，这一段要么只有 $a[i]$ 自己，要么是以 $a[i-1]$ 结尾的最优段再接上 $a[i]$：

$$g[i]=a[i]+\max\{0,\ g[i-1]\}\qquad(i\ge2).$$

逐项算：$g=[-2,1,-2,4,3,5,6,1,5]$。答案是 $\max g[i]=6$，对应子段 $4,-1,2,1$。如果状态设成「前 $i$ 个数里的最大子段和」，新来的数能不能接上，要看最优子段是否正好结束在 $i-1$，信息就丢了，和第 1 节开头的情形一样。

> 求 $[1,-2,3,-1,2]$ 的连续子段最大和。
>
> 答案：$g[1]=1$，$g[2]=-2+\max\{0,1\}=-1$，$g[3]=3+\max\{0,-1\}=3$，$g[4]=-1+3=2$，$g[5]=2+2=4$，最大是 4，子段为 $3,-1,2$。

**例 11**　一排房子，价值依次为 $[2,7,9,3,1]$，不能同时拿相邻的两间，求最大总价值。和例 10 相比，这里的限制只涉及相邻两间，用「前 $i$ 个」做状态就够。

问第 1 问：最后一步是第 $i$ 间拿不拿。设 $f[i]$ 是前 $i$ 间的最大价值（价值都是正数，可以一间都不拿，所以 $f[0]=0$）。不拿，价值为 $f[i-1]$；拿，第 $i-1$ 间就不能拿，价值为 $f[i-2]+a[i]$。

$$f[i]=\max\{f[i-1],\ f[i-2]+a[i]\}\quad(i\ge2),\qquad f[0]=0,\ f[1]=a[1].$$

$f=[0,2,7,11,11,12]$，答案是 12（拿 2、9、1）。为什么这里不用钉结尾？因为「不能同时拿相邻两间」这个条件，只用转移式里隔一格的下标就表达完了，不必知道前面选了谁。

**例 12**　求 BBABCBCAB 的最长回文子序列的长度（回文：正读反读相同）。这一题和前面的都不像，按三问从头设计。

第 1 问：最后一步看串的**两端**。回文的两头必须相同，所以这里的状态是区间，记 $s_i\cdots s_j$ 的最长回文子序列长度为 $P[i][j]$。第 2、3 问：两端 $s_i=s_j$ 时，把它们当作回文的两头，里面是 $P[i+1][j-1]$；两端不等时，两个字符不可能同时是回文的两头，丢掉一个，剩下 $P[i+1][j]$ 或 $P[i][j-1]$。

$$P[i][j]=\begin{cases}P[i+1][j-1]+2,&s_i=s_j,\\ \max\{P[i+1][j],\ P[i][j-1]\},&s_i\ne s_j,\end{cases}\qquad P[i][i]=1,\ i>j\text{ 时 }P=0 .$$

这和 LCS 的转移几乎一样，只是向里收缩的是两端。按区间长度从短到长算（和方法 5 同样的顺序）。整串的两端都是 B，所以要看里面的 BABCBCA，一路拆下去，用到的几个区间依次是：

| 区间 | 两端 | 取值 |
|---|---|---|
| CBC、BCB | 相等 | 各是 $2+1=3$ |
| BCBC | B 与 C 不等 | $\max\{P(\text{CBC}),P(\text{BCB})\}=3$ |
| ABCBCA | 都是 A | $2+P(\text{BCBC})=5$ |
| BABCBC | B 与 C 不等 | 3 |
| BABCBCA | B 与 A 不等 | $\max\{5,3\}=5$ |
| 整串 BBABCBCAB | 都是 B | $2+5=7$ |

最长回文子序列长度是 7，例如 BABCBAB。

这道题说明状态不一定是前缀，要看最后一步关心的是串的哪里。把本章的几种设法放在一起看：

| 最后一步关心什么 | 状态 | 例 |
|---|---|---|
| 新元素能否接在某个结尾后面 | 以第 $i$ 个结尾 | LIS（例 1）、连续子段和（例 10） |
| 新元素只与隔一格的状态有关 | 前 $i$ 个 | 不取相邻（例 11） |
| 两个串的末字符怎样配 | 两串各取前几个 | LCS、编辑距离（例 3、5） |
| 一次分割或两端同时收缩 | 区间 $[i,j]$ | 矩阵连乘（例 9）、回文（例 12） |

合上书，用这三问复述本章四种状态各自的「最后一步」和「要记住什么」，再各找一道题对照。

### 本章小结
