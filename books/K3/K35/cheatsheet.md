## K3.5 · 动态规划（二）：序列上的动态规划（速记）

| 提示 | 内容 |
|---|---|
| 子序列与子串 | 子序列保持先后顺序、可以不相邻；上升子序列要严格增大 |
| 以谁结尾 | $d[i]=1+\max\{d[j]\mid j<i,\ a[j]<a[i]\}$（空集取 0）；答案是 $\max_i d[i]$，不是 $d[n]$；时间 $\Theta(n^2)$ |
| 状态缺信息的信号 | 新元素能否接上取决于「上一个选了谁」，就必须把结尾钉进状态 |
| LCS 转移 | $x_i=y_j$：$c[i][j]=c[i-1][j-1]+1$；否则 $c[i][j]=\max\{c[i-1][j],c[i][j-1]\}$；边界 $c[i][0]=c[0][j]=0$；时间 $\Theta(mn)$ |
| LCS 与 LIS | 各数互不相同时，LIS 等于 $a$ 与排好序的 $a$ 的 LCS；有重复数时求出的是最长不降子序列 |
| 编辑距离 | $e[i][j]=\min\{e[i-1][j]+1,\ e[i][j-1]+1,\ e[i-1][j-1]+[x_i\ne y_j]\}$；$e[i][0]=i$，$e[0][j]=j$ |
| 只许插入删除 | 最少操作数是 $m+n-2\cdot\mathrm{LCS}$，kitten→sitting 为 5，允许替换为 3 |
| LCS 的两个错做法 | 末字符不等时只看左上角会错（AB 与 BA）；见到能配就先配的扫描也会错（ABC 与 BCA） |
| 回溯 | 从右下角出发，看值由哪一格得来；LCS 相等走左上并收字符，否则走较大的一方；并列时方案不唯一 |
| 空间 | 只要值：沿较短的一维两行滚动，$\Theta(\min(m,n))$；要方案：保留整表，$\Theta(mn)$ |
| 区间动态规划 | $M[i][j]=\min_{i\le k<j}\{M[i][k]+M[k+1][j]+p_{i-1}p_kp_j\}$，$M[i][i]=0$；按区间长度从短到长填；时间 $\Theta(n^3)$ |
| 设计状态三问 | 最后一步是什么；要记住什么；规模怎样缩小（前缀长度、区间端点、剩余容量） |
| 「前 $i$ 个」还是「以 $i$ 结尾」 | 连续子段、上升子序列要钉结尾；不选相邻这类只看隔一格的条件，前 $i$ 个就够 |
| 老朋友① | $[5,2,8,1,9,3]$：$d=[1,1,2,1,3,2]$，最长上升子序列长 3 |
