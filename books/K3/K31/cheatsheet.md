## K3.1 · 复杂度：程序要跑多少步 · 速记表

| 提示 | 内容 |
|---|---|
| 读伪代码 | 赋值用 `←`，数组下标从 1，`for i ← 1 to n` 做 $n$ 遍（遇到 `return` 会提前结束），`while` 用条件决定是否继续，次数要由条件和变量的变化推导；$\lfloor x\rfloor$ 向下取整，$\lceil x\rceil$ 向上取整。读不懂就做追踪表：每个变量一列，每执行一步写一行 |
| 数基本操作 | 选最里层的比较；从里往外数，里层的次数常依赖外层变量，再对外层求和。用 $n=3$ 或 $6$ 回头核对 |
| 常用求和 | $\sum_{k=1}^{m}k=\frac{m(m+1)}2$，$\sum_{k=1}^{m}k^2=\frac{m(m+1)(2m+1)}6$，$\sum_{k=0}^{m}2^k=2^{m+1}-1$ |
| 常见循环的次数 | 单层 $n$；$j$ 从 $i+1$ 到 $n$ 的双层 $\frac{n(n-1)}2$；$j$ 从 1 到 $i$ 的双层 $\frac{n(n+1)}2$。$j=1$、条件 $j\le n$、每轮乘 2：$\lfloor\log_2 n\rfloor+1$ 次；条件改为 $j<n$：$\lceil\log_2 n\rceil$ 次；`HALVE` 从正整数 $n$ 开始、条件 $n>1$、每轮取整除以 2：$\lfloor\log_2 n\rfloor$ 次（$n=8$ 时分别是 4、3、3 次） |
| 最好、最坏、平均 | 同一规模的输入里取次数最少、最多、按分布求平均；没有另外说明时，运行时间指最坏情况。顺序查找：$1$、$n$；保证成功且首次命中位置等可能时平均 $\frac{n+1}2$ |
| $O,\Omega,\Theta$ | $O$：$n\ge n_0$ 时 $f\le cg$（天花板）；$\Omega$：$f\ge cg$（地板）；$\Theta$：两者都有（夹住）。$O$ 与「最坏情况」是两个维度，不要混 |
| 定阶规则 | 常数倍丢掉；几项相加留最大的；顺序执行取最大；嵌套循环先固定外层再对外层求和，仅当每轮内层次数相同才直接相乘；对数的底取固定的大于 1 的数时可以丢。指数里的常数倍不能丢：$2^{n+1}=\Theta(2^n)$，$2^{2n}\ne O(2^n)$ |
| 极限判别 | $\lim\frac fg=0$：$f=O(g)$ 且不是 $\Theta$；$0<L<\infty$：$\Theta$；$=\infty$：$f=\Omega(g)$ 且不是 $O$ |
| 增长次序 | 对固定的 $0<a<1$：$1\prec\log n\prec n^a\prec n\prec n\log n\prec n^2\prec n^3\prec2^n\prec n!\prec n^n$；规模很小时阶高的也可能更快（整数 $2\le n\le9$ 时 $n^3>2^n$） |
| 递归三要素 | 出口、递归调用（参数必须变小）、把小问题的答案拼成大问题的答案。正确性：出口对应归纳起点，递归调用对应归纳假设；参数是 $\lfloor n/2\rfloor$ 时用强归纳 |
| 递归的空间 | 同时在等的调用越多越占内存：`SUM` 深度 $n+1$，空间 $\Theta(n)$；`POW`（$n\ge1$）深度 $\lfloor\log_2 n\rfloor+2$，每层空间固定，总空间 $\Theta(\log n)$ |
| 递推式与递归树 | $T(n)=T(n-1)+1,\ T(0)=0\Rightarrow n$；汉诺塔 $H(n)=2H(n-1)+1,\ H(1)=1\Rightarrow2^n-1$；朴素斐波那契的调用数 $C(n)=C(n-1)+C(n-2)+1,\ C(0)=C(1)=1\Rightarrow2F(n+1)-1$。画树：结点写自己的工作，按层求和 |
| 主定理 | $a,b$ 为固定正整数（$b\ge2$），$d\ge0$，$n=b^k$，$T(1)=1$，$T(n)=aT(n/b)+n^d$：$a<b^d$ 得 $\Theta(n^d)$（根重）；$a=b^d$ 得 $\Theta(n^d\log n)$（层层相等）；$a>b^d$ 得 $\Theta(n^{\log_b a})$（叶子重）。形状不符（$T(n-1)$、$n\log n$ 合并、子问题不等大）回到递归树 |
