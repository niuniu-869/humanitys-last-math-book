**K31-01**〔A｜方法 1 · 考查：赋值后的条件与提前返回〕对数组 $A=[3,-5,7,-1]$ 执行 `FIRST(A,4)`。列出实际执行的每轮结束时 $i,s$ 的值，写出返回值，并数出 `s ← s + A[i]` 和 $s<0$ 各执行几次。

```text
FIRST(A, n)
    s ← 0
    for i ← 1 to n
        s ← s + A[i]
        if s < 0
            return i
    return 0
```

**K31-09**〔B｜方法 5 · 考查：对区间长度作强归纳〕设数组 $A$ 含有 $N$ 个实数，$1\le l\le r\le N$。证明下列程序总会结束，并返回 $A[l],A[l+1],\dots,A[r]$ 中的最大值。证明中须说明两次递归调用的区间为什么非空且更短。

```text
BLOCKMAX(A, l, r)
    if l = r
        return A[l]
    q ← ⌊(l + r) / 2⌋
    u ← BLOCKMAX(A, l, q)
    v ← BLOCKMAX(A, q + 1, r)
    if u ≥ v
        return u
    return v
```
