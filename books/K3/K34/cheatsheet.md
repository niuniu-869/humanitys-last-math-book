## K3.4 · 动态规划（一）：从贪心到填表（速记）

| 提示 | 内容 |
|---|---|
| 贪心 | 每步取眼前最好、不反悔；一个小反例就能推翻；面额 1、3、4 付 6：贪心 4+1+1 共 3 枚，最优 3+3 共 2 枚；面额 1、5、11 付 15：贪心 5 枚，最优 3 枚 |
| 重叠子问题 | 同一个参数被反复算；Fib(5) 调用树 15 次调用；调用次数 $C(n)=2F(n+1)-1$，$n=30$ 时 2692537 次，指数级 |
| 记忆化 | 查表、算完先写表再返回；每个子问题只算一次，Fib 做 $n-1$ 次加法，$O(n)$ |
| 走楼梯 | $f(k)=f(k-1)+f(k-2)$，$f(0)=f(1)=1$，$f(10)=89$；可走 1、2、3 级时 $f(7)=44$ |
| 四要素 | 状态（写清 $f(\cdots)$ 表示什么）、转移（最后一步怎么来，不重不漏）、边界、填表顺序（依赖的先填）；时间 = 状态数 × 每状态转移代价 |
| 网格路数 | $f(i,j)=f(i-1,j)+f(i,j-1)$，$f(1,1)=1$；$4\times4$ 点阵 20 = $\binom63$；障碍点 $f=0$ |
| 最小代价路径 | $g(i,j)=c_{ij}+\min(g(i-1,j),g(i,j-1))$；最少、最多问题把「加」换成取最小或最大 |
| 老朋友 ② 只往字母大走 | 从 A 到 F 路数 8；最短路 14（A–B–D–E–F），比不限方向的 13 大 |
| 最少硬币 | $dp[a]=1+\min_{c\le a}dp[a-c]$，$dp[0]=0$，凑不出记 $\infty$；面额 1、3、4：$dp[6]=2$；最优子结构：去掉最后一枚剩下的仍最优 |
| 0/1 背包 | $d[i][c]=\max(d[i-1][c],\ d[i-1][c-w_i]+v_i)$，$d[0][c]=0$；时间 $O(nW)$ 是伪多项式；回头读选法：$d[i][c]>d[i-1][c]$ 说明一定选了第 $i$ 个，相等时约定不选 |
| 贪心为何错在背包 | 按价值÷成本选，例中得 11，最优 12（项目 2 和 4） |
| 滚动数组 | 转移只依赖上一行就压成一行；0/1 背包 $c$ 从大到小，完全背包 $c$ 从小到大；一个物品、容量 6：倒序 $[0,0,3,3,3,3,3]$，正序 $[0,0,3,3,6,6,9]$ |
| 数凑法 | 面额在外层数的是组合，金额在外层数的是有序排列；面额 1、3 凑 4：2 种与 3 种 |
| 交换论证 | 设最优方案，把第一处不同换成贪心的选择，不变差；区间调度取结束最早；最早开始、最短优先都有反例；目标换成总收益最大时最早结束优先也会错 |
| 面额 1、5、10、25 | 贪心恰好最优：$p\le4,\ n\le1,\ d\le2$，且 $n=1,d=2$ 时可换成一枚 25 分 |
