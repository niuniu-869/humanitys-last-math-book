## K3.3 · 查找与搜索：怎么找、按什么顺序走（速记）

| 提示 | 内容 |
|---|---|
| 二分查找 | 数组必须有序；区间 $[lo,hi]$，$mid=\lfloor(lo+hi)/2\rfloor$；小了 $lo\leftarrow mid+1$，大了 $hi\leftarrow mid-1$；$lo>hi$ 为没有 |
| 循环不变量 | 若 $x$ 在数组里，则位置在 $[lo,hi]$ 内：开头成立、一轮后仍成立、结束时区间为空，得出「不在」 |
| 二分的次数 | 每轮剩下的位置至多减半，最坏 $\lfloor\log_2 n\rfloor+1=\lceil\log_2(n+1)\rceil$ 次；$n=10^6$ 时 20 次 |
| 第一个不小于 $x$ | 半开区间 $[lo,hi)$，$hi$ 从 $n+1$ 起；小了 $lo\leftarrow mid+1$，否则 $hi\leftarrow mid$；$x$ 的个数 = 首个 $\ge x+1$ 的位置 − 首个 $\ge x$ 的位置（整数） |
| 二叉搜索树 | 左子树 < 根 < 右子树；中序读出来是有序的；成功查找的比较次数 = 结点深度，失败查找数经过的结点；有序插入退化成链，查找 $O(n)$ |
| 删除结点 | 叶子直接摘；一个孩子让孩子顶上；两个孩子用右子树最小的数替换 |
| 栈与队列 | 栈后进先出（括号配对、递归、DFS）；队列先进先出（轮流服务、BFS）；单次操作 $O(1)$ |
| BFS | 队列；起点距离 0；点第一次被发现时记 $dist=dist[u]+1$ 并记来路；次序按层；无权图最短路；$O(V+E)$ |
| DFS | 栈或递归；到点先标记再走未访问邻居，走完退回；连通块；无向图判环（遇到已访问且不是来路的点）；$O(V+E)$ |
| 老朋友 ② 的次序 | 从 E 出发，邻居按字母序：BFS 是 E C D F A B（第 1 层 C D F，第 2 层 A B）；DFS 是 E C A B D F |
| 回溯与剪枝 | 分步选择，每选一步立即检查已能检查的条件，违反就剪掉整棵子树；走到底记解，撤销后换下一个选项；4 皇后 2 解，8 皇后 92 解 |
| DPLL | 单子句传播（其余文字全假，剩下的必须真）；冲突就撤销最近一次猜测、改猜相反的值；两种猜法都冲突则无解 |
| 编码成 SAT | 「至少一个」一个长子句，「至多一个」每对一个子句 $(\neg p\lor\neg q)$；两端颜色不同 = $(x_u\lor x_v)\land(\neg x_u\lor\neg x_v)$ |
| 拓扑排序 | 只对有向无环图；反复取入度为 0 的点，删出边；输出不足总数则有环；结果一般不唯一 |
| 迪杰斯特拉 | 边权必须 $\ge0$；每轮取未定点中 $d$ 最小的定下来，更新它的未定邻居；老朋友 ② 从 A 出发最短路 A–C–B–D–E–F，长 13 |
