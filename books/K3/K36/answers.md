**K36-03**

**K36-05**

### B 进阶

**K36-06**
**答案：** 空数组错误地返回 1，应返回 0。最短非空反例可取 $[1,2,1]$：原代码返回 2，前缀为 $[1,2]$，但三段都应保留。示例数组虽返回 3，前缀却是 $[2,5,5]$，应为 $[2,5,2]$。

示例中，读到第二个 2 时跳过；两个 5 都与首项 2 不同，分别写入位置 2、3；最后的 2 又被跳过。错误在于一直与首项比较，无法识别当前段。长度为 1 时正确；长度为 2 时，只需判断两项是否相等，原代码也正确，所以非空反例至少长 3。

先处理空数组，再与已保留的最后一个元素比较：

```text
if n = 0
  return 0
k ← 1
for i ← 2 to n
  if a[i] ≠ a[k]
    k ← k + 1
    a[k] ← a[i]
return k
```

读取第 $i$ 项前，前 $k$ 项是前 $i-1$ 项压缩后的结果，$a[k]$ 是最后一段的值。相等就延续该段，不等才添加新段。此时 $k\le i-1$，增加后仍有 $k\le i$，因此写入不会碰到第 $i$ 项之后尚未读取的元素。

区分点：原地压缩要与当前保留的末项比较，还要分别检查返回长度和有效前缀。

**K36-07**
**答案：** 第一个循环得到 $[3,5,1,10]$，第二个循环得到 $[3,8,9,19]$。把第一个循环改成 `for i ← n downto 2`，即可恢复任意原数组；`downto` 表示每次减 1，包含终点 2。

原循环计算第三项时，减的是已更新的 5，故得 $6-5=1$，不是原相邻差 $6-8=-2$。逆向遍历时，$a[i-1]$ 尚未修改，因此得到 $[3,5,-2,5]$。

一般记原数组为 $b$，逆向循环得到 $d_1=b_1$、$d_i=b_i-b_{i-1}$；随后正向累加，第 $i$ 项就是 $d_1+\cdots+d_i=b_i$。$n=1$ 时两个循环都不执行。

区分点：加减符号相反并不保证互逆；必须检查两次操作读取的是哪一时刻的相邻项。

**K36-08**
**答案：** 两轮为 $(2,4,9)$、$(3,4,11)$，返回 $(0,0,0)$，漏掉 $(2,3,4)$，因为 $2+4+6=12$。所谓不变量在初始化时就不成立：没有理由保证答案包含位置 1。

固定位置 1 后，双指针能正确排除与它配对的候选；这些排除不能说明不含位置 1 的三元组也无解。长度小于 3 时无三元组；长度为 3 时唯一的一组就是 $(1,2,3)$，会直接检查，因此长度 4 最小。

一种修正是逐组枚举：

```text
for i ← 1 to n − 2
  for j ← i + 1 to n − 1
    for k ← j + 1 to n
      if a[i] + a[j] + a[k] = t
        return (i, j, k)
return (0, 0, 0)
```

每组三个不同位置按递增顺序恰好检查一次，未改动数组，所以返回的是原下标。无解时遍历全部三元组，$n\ge3$ 时最坏检查次数为
$$\frac{n(n-1)(n-2)}6.$$
分母 6 来自三个位置的六种排列只保留递增的一种。对 $n\ge4$，次数在 $n^3/24$ 与 $n^3/6$ 之间，故最坏时间为 $\Theta(n^3)$；$n<3$ 时检查 0 次。

区分点：排除规则在固定位置下有效，不代表固定这个位置就覆盖了全部答案。

**K36-09**
**答案：** (D)，分别为 $S+n$、$L+n$。$n=8$ 时，$S=1+2+2+3+3+3+3+4=21$、$L=4$，故判断次数为 29、12。两版时间阶分别为 $\Theta(n\log n)$、$\Theta(n)$。

甲每轮重置，条件成立次数为 $\lfloor\log_2i\rfloor+1$。乙共享 `j`，全程依次用到 $1,2,4,\ldots,2^{L-1}$，每个值只使条件成立一次，共 $L$ 次。两版每个外层轮次都另有一次失败判断，即使该轮根本不进入内层也要判断，所以都加 $n$。

(A) 只数成立的判断。(B) 只加了整个程序最后一次失败，漏掉其余外层轮次的失败。(C) 把乙也当成每轮重置。

甲中 $S\le n(\log_2n+1)$；对 $n\ge4$，后半部分至少 $n/2$ 项各大于 $\log_2(n/2)$，由此得到同阶下界。乙中 $1\le L\le n$，所以 $n\le n+L\le2n$。两版其余操作与判断次数至多相差常数倍，时间阶如上。

区分点：共享变量减少的是成功进入循环的次数，每轮结束的失败判断仍各有一次。

**K36-10**
**答案：** $n=9$ 时返回 20。条件判断执行 $n(n-1)/2$ 次，自增执行
$$c=\begin{cases}m^2,&n=2m,\\m(m+1),&n=2m+1,\end{cases}\qquad c=\lfloor n^2/4\rfloor.$$

因为和为奇数当且仅当两个下标一奇一偶，所以从 $\lceil n/2\rceil$ 个奇数和 $\lfloor n/2\rfloor$ 个偶数中各选一个，就得到一个合格位置对。按大小排列后恰有一个满足 $i<j$，无须再除以 2。$n=9$ 时为 $5\cdot4=20$，而条件判断执行 36 次。

当 $n\ge2$ 时，$\lfloor n/2\rfloor\ge n/4$、$\lceil n/2\rceil\ge n/2$，所以 $n^2/8\le c\le n^2/4$，上下界同阶。这里把 K3.1 的逐轮计数改写成了对合格下标对的计数。

区分点：条件判断与通过条件的次数不同；奇偶两类已经区分角色，不应机械地再除以 2。

**K36-11**
**答案：** 代码一定停止，返回的正是商和余数，而且这个数对唯一。

开始时 $q=0,r=a$，所以不变量 $a=bq+r$ 成立，且 $r\ge0$；$q,r$ 都是整数，后续整数加减也保持这一点。

若一轮开始时成立，因为进入循环须有 $r\ge b$，更新后 $r-b\ge0$，且
$$b(q+1)+(r-b)=bq+r=a.$$
所以每一轮都保持等式与非负性。

退出时 $r<b$，结合不变量便得到要求。

为说明会退出，注意每轮让非负整数 $r$ 减少正整数 $b$，所以循环至多执行 $\lfloor a/b\rfloor$ 轮；不变量本身不能代替这一步。

若另有整数 $q',r'$ 满足 $a=bq'+r'$ 且 $0\le r'<b$，相减得
$$b(q-q')=r'-r.$$
右侧绝对值小于 $b$，左侧是 $b$ 的整数倍，只能同为 0，因此 $q=q'$、$r=r'$。

区分点：等式保持只能说明退出时结果对，还要单独保证会退出，并用余数范围说明结果唯一。

### C 提高

**K36-12**
**答案：** `T(7)` 输出 $3,3,7$，输出 3 次，调用 10 次。当 $n=2^m-1$、$m\ge1$ 时，
$$P(n)=2^{m-1}-1,\qquad C(n)=3\cdot2^{m-1}-2.$$

`T(7)` 先调用 `T(6)`，后者按顺序调用两次 `T(3)`。每次 `T(3)` 都先执行 `T(2)` 及它的两个 `T(1)`，再输出 3。因此每棵 `T(3)` 子树有 4 次调用，加上 `T(6)` 和 `T(7)` 共 $2\cdot4+2=10$ 次；最后才输出 7。

初值为 $P(1)=0,C(1)=1$。对偶数 $n\ge2$，当前调用不输出，并执行两个相同规模的孩子，所以
$$P(n)=2P(n/2),\qquad C(n)=1+2C(n/2).$$
对奇数 $n\ge3$，当前调用执行一个孩子后再输出一次，所以
$$P(n)=P(n-1)+1,\qquad C(n)=1+C(n-1).$$

为处理指定的输入，记 $p_m=P(2^m-1)$、$c_m=C(2^m-1)$。当 $m\ge2$ 时，先减 1，再走偶数分支，其两个孩子的参数都是 $2^{m-1}-1$，因此
$$p_m=2p_{m-1}+1,\qquad c_m=2c_{m-1}+2.$$
由 $p_1=0,c_1=1$，展开得到
$$p_m=\sum_{h=0}^{m-2}2^h=2^{m-1}-1,$$
$$c_m=2^{m-1}+2\sum_{h=0}^{m-2}2^h=3\cdot2^{m-1}-2.$$
$m=1$ 时求和为空，按 0 计，公式仍成立。只有大于 1 的奇数调用会输出；偶数调用和出口调用均不输出，所以输出次数少于调用次数。

区分点：先按实际进入的分支写递推，再合并两步变化；输出结点只占调用树的一部分。

**K36-13**
**答案：** $C(10)=16$。令 $M=\lfloor\log_2n\rfloor$，则
$$C(n)=\sum_{k=0}^{M}\min(2^{k+1},n-2^k+1).$$
当 $n=2^m$ 时，$m=0$ 给出 $C(1)=1$；$m\ge1$ 时 $C(n)=3n/2$。对所有 $n\ge1$，有 $n/2<C(n)<4n$，因此 $C(n)=\Theta(n)$，题中断言错误。

$n=10$ 时区间依次为 $[1,2]$、$[2,5]$、$[4,10]$、$[8,10]$，长度为 $2,4,7,3$，和为 16。不同轮的重叠位置会再次执行自增，不能合并后只数一次。

当 $i=2^k$ 时，未截断区间 $[i,3i-1]$ 有 $2i$ 项；在 $n$ 处截断后只剩 $n-i+1$ 项，取两者较小值即得求和式。

当 $n=2^m,m\ge1$ 时，$k=0,\ldots,m-2$ 的区间未截断，最后两轮的长度为 $n/2+1$ 和 1。因此
$$C(n)=\sum_{k=0}^{m-2}2^{k+1}+(n/2+1)+1=(n-2)+(n/2+1)+1=3n/2.$$
$m=1$ 时前面的和为空，仍按 0 计。

对一般的 $n$，每轮长度至多 $2^{k+1}$，故
$$C(n)\le\sum_{k=0}^{M}2^{k+1}=2^{M+2}-2<4n.$$
对 $k<M$，有 $n\ge2^{k+1}$，该轮至少扫描 $2^k$ 项；最后一轮至少 1 项。所以
$$C(n)\ge\sum_{k=0}^{M-1}2^k+1=2^M>n/2.$$
上下界同阶；用轮数乘每轮最大长度只能给较松的上界。

区分点：先数每个截断区间的实际长度，再求和；重叠区间与最后几轮都不能漏计。

**K36-14**
**答案：** 最小反例是任意单元素数组，例如 $[7]$，原代码返回 0，正确值为 1。示例数组上的原代码最终返回 2，应返回 3。

处理完前 $i$ 项后，原代码的 $(run,best)$ 在 $i=1,2,3,4,5$ 时依次为 $(1,0),(2,0),(1,2),(2,2),(3,2)$。它只在遇到不同元素时结算前一段，最后一段没有进入 `best`。

可改为每处理一个元素都更新最大长度：

```text
Longest(a, n):
  if n = 0
    return 0
  run ← 1
  best ← 1
  for i ← 2 to n
    if a[i] = a[i−1]
      run ← run + 1
    else
      run ← 1
    best ← max(best, run)
  return best
```

处理完前 $i$ 项时，`run` 是以第 $i$ 项结尾的相同段长度，`best` 是前 $i$ 项中最长相同段的长度。$i=1$ 时两者均为 1，不变量成立。

为验证一轮保持，先假设处理完前 $i-1$ 项时成立。

1. 新元素与前项相等时，原末段延长一项，`run` 加 1。
2. 新元素与前项不等时，只能从当前项开始新段，`run` 设为 1。
3. 两种分支结束后，都用 `best ← max(best, run)` 更新。未以当前项结尾的段已包含在旧 `best` 中，新末段的长度是更新后的 `run`，取最大值覆盖了全部候选。

因此每轮保持不变量，$i=n$ 时返回所求值。循环下标走到 $n$ 就停止。

空数组直接返回 0；单元素不进入循环，返回 1；全部相同时 `run` 每轮加 1，`best` 随之更新，返回 $n$。

相邻元素比较次数为 $\max(n-1,0)$，非空输入的时间为 $\Theta(n)$，空输入为常数时间；额外空间为 $O(1)$。

区分点：不变量须包含当前尚未结束的一段；只统计已结束的段，会在最后一段最长时漏掉答案。
