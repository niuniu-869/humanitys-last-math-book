**K36-07**〔B｜方法 1、5 · 考查：两个看似相反的操作是否互相抵消〕以下两个循环依次作用于同一个数组 $a=[3,8,6,11]$。写出第一个循环结束和第二个循环结束时的数组。有人说「先减相邻项，再加相邻项，一定回到原数组」，指出问题，并只改变第一个循环的遍历方向，使两个循环对任意非空数组都能恢复原数组。

```text
for i ← 2 to n

```

**K36-08**〔B｜方法 3、5 · 考查：局部排除能否覆盖全部候选〕给定非降序整数数组，要求找出三个不同下标 $i<j<k$，使 $a[i]+a[j]+a[k]=t$，找到任意一组即可；没有则返回 $(0,0,0)$。有人固定第一个位置，再用双指针寻找另外两个位置：

```text
ThreeSum(a, n, t):
  if n < 3
    return (0, 0, 0)
  lo ← 2
  hi ← n
  while lo < hi
    s ← a[1] + a[lo] + a[hi]
    if s = t
      return (1, lo, hi)
    if s < t
      lo ← lo + 1
    else
      hi ← hi − 1
  return (0, 0, 0)
```

2. 判断「若存在答案，它始终由位置 1 和区间 $[lo,hi]$ 内的两个位置组成」是否是不变量；指出最先失败的环节，并说明反例长度为什么最小。
3. 写出枚举所有 $i<j<k$ 的修正版，返回原数组下标，并给出最坏情况下的检查次数与时间阶。

**K36-09**〔B｜方法 4 · 考查：重置与共享变量时的条件判断次数〕（选择）设 $n\ge2$ 为整数。下面两版代码都只统计条件 `j ≤ i` 被判断的次数，包括每轮最后一次不成立的判断，不计 `for` 自身的判断。令 $L=\lfloor\log_2n\rfloor+1$、$S=\sum_{i=1}^n(\lfloor\log_2i\rfloor+1)$。两版的判断次数依次为（　）。

**K36-11**〔B｜方法 3 · 考查：不变量与终止性承担不同任务〕（证明）设 $a$ 为非负整数，$b$ 为正整数。证明以下代码一定停止，并返回唯一满足 $a=bq+r$、$0\le r<b$ 的整数数对 $(q,r)$。按「开始成立、一轮保持、退出时的含义、为什么会停」写出证明，再说明唯一性。
