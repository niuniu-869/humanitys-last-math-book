## K3.6 · 读伪代码：追踪、计数与找错（速记）

| 提示 | 内容 |
|---|---|
| 读陌生代码第一步 | 挑小输入，画追踪表（每轮一行，每个变量一列，数组写整个）；先追踪，再猜，再证明 |
| 猜规律后怎么证 | 对循环轮数用归纳法：第 $k$ 轮结束后变量满足什么；起点是循环开始前的值 |
| 调用树 | 结点是一次调用，孩子按调用先后从左到右排；输出次序看 `print` 在调用之前、之间还是之后；调用次数是结点个数（含立刻返回的出口） |
| 斐波那契式递归的调用数 | $C(n)=1+C(n-1)+C(n-2)$，$C(n)=2F_{n+1}-1$，$C(10)=177$ |
| 汉诺塔 | 搬动 $2^n-1$ 次，调用 $2^{n+1}-1$ 次；$T(n)=2T(n-1)+1$ 与循环 $x\leftarrow2x+1$ 同一个式子 |
| 循环不变量认功能 | 找每轮开始时都成立的关系；验证开始成立、一轮保持；用终止条件读出返回值；另找严格变小的量证明会停 |
| 辗转相除 | 不变量 $\gcd(a,b)=\gcd(a_0,b_0)$（关键等式 $\gcd(a,b)=\gcd(b,a\bmod b)$），返回 $\gcd$；追踪表里每行数对的最大公约数相同，是找不变量的线索 |
| 快速幂 | 不变量 $r\cdot g^{e}=a^{n}$，轮数 $\lfloor\log_2n\rfloor+1$ |
| 精确计数 | 内层次数依赖外层变量时写成求和；$j$ 翻倍到 $n$ 共 $\lfloor\log_2n\rfloor+1$ 次 |
| 什么时候写 $\Theta$ | 必须同时论证上界和下界；粗估的 $O$ 可能太松（完全平方数处才跑内层：$\Theta(n^{3/2})$ 而非 $\Theta(n^2)$） |
| 最好与最坏不同 | 线性查找最好 $\Theta(1)$、最坏 $\Theta(n)$，整个算法没有统一的 $\Theta$ |
| 找错的输入清单 | 空或单元素、全相同、已排好、逆序、目标在两端或不存在、全是负数；一个反例推翻，再多正例不能证明 |
| 常见错误位置 | 初值（最大值取 0）、`lo ← mid` 而非 `mid+1`（死循环）、`j > 1` 而非 `j ≥ 1`（第一个元素不动） |
| 设计算法六步 | 输入输出与边界；小例子；思路；伪代码；证明正确（不变量）；复杂度 |
| 双指针两数之和 | 升序数组，和太小丢左端，太大丢右端；不变量：答案在 $[lo,hi]$ 内；最坏 $\Theta(n)$；数组没排序时会漏答案 |
