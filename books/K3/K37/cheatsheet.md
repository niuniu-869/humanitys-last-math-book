## K3.7 · 随机化算法：让算法掷骰子（速记）

| 提示 | 内容 |
|---|---|
| 随机快排 | 基准在当前段里等可能选（交换到段尾再划分）；对每个固定的互异输入（有重复数时随机基准也救不了全相同的数组），比较次数的分布相同，运行时间是随机变量，最坏的运气仍可能出现 |
| 两种「平均」 | 平均情况分析：假设输入随机、算法确定；随机化算法的期望：输入任意、算法自己掷骰子 |
| 递推 | $E(n)=(n-1)+\frac1n\sum_{k=0}^{n-1}(E(k)+E(n-1-k))$；$E(3)=\frac83$，$E(4)=\frac{29}6$，$E(6)=\frac{103}{10}$（最坏 15） |
| 指示变量 | 总量 $=\sum$ 0/1 变量；$E[X_A]=P(A)$；线性性不要求独立 |
| 被比较的概率 | 排好后第 $i$、$j$ 小的数被比较的概率 $=\frac2{j-i+1}$：看它们之间的 $j-i+1$ 个数里谁先做基准，只有端点先被选才比较 |
| 期望比较次数 | $\sum_{d=1}^{n-1}(n-d)\frac2{d+1}\le2n\ln n\approx1.39\,n\log_2n$（用 $\sum_{k=2}^n\frac1k\le\ln n$） |
| 哈希表 | 槽 + 哈希函数 + 链地址法；成功查找比较到目标即停，失败查找扫整链，链长是比较次数上界；固定函数可能被坑 |
| 链长期望 | $n$ 个键、$m$ 个槽，每个键落进给定槽的概率 $\frac1m$，固定槽期望链长 $\frac nm=\alpha$（只需边缘均匀）；对固定的不在表中的查询键，再加上它与各键冲突概率 $\le\frac1m$ 和常数时间的基础操作，查找期望 $O(1+\alpha)$ |
| 只要「每对冲突概率 $\le\frac1m$」 | 与某键冲突的键个数的期望 $\le\frac{n-1}m$（线性性，不要求独立） |
| 生日问题 | $P(\text{无冲突})=\prod_{i=0}^{n-1}(1-\frac im)\le e^{-n(n-1)/(2m)}$（用 $1-x\le e^{-x}$）；需 $1\le n\le m$；$m=365$ 时 $n=23$ 冲突概率 0.5073 |
| 冲突何时出现 | 冲突概率过半在 $n\approx1.18\sqrt m$；$n$ 与 $\sqrt m$ 同量级时冲突已不能忽略，要无冲突概率 $\le0.01$ 需 $\frac{n(n-1)}{2m}\ge\ln100$；$m=2^{32}$ 时约 77000 个键 |
| 蒙特卡洛 | 时间有预先控制的上界（实际用时可随机），答案可能错；本节矩阵检验每轮漏检率至多 $\frac12$，各轮独立且任一轮发现错误就拒绝，$t$ 轮全漏检概率至多 $2^{-t}$ |
| 矩阵乘积验证 | 随机 $\boldsymbol r\in\{0,1\}^n$，比较 $A(B\boldsymbol r)$ 与 $C\boldsymbol r$；$AB=C$ 时必相等，$AB\ne C$ 时被骗过去概率 $\le\frac12$（要求各分量独立，若 $\boldsymbol r=(b,b)$ 可能恒被骗过）；时间 $\Theta(n^2)$ |
| 拉斯维加斯 | 答案总对，时间随机；每轮成功概率同为 $p$（$0<p\le1$，各轮独立），期望次数 $\frac1p$（$E=1+(1-p)E$）；每次代价同为常数 $c$ 时总代价 $\frac cp$ |
| 接受—拒绝 | 本章只讲有限候选的情形：候选分布 $q$ 在目标有正概率之处也为正（$p_x>0\Rightarrow q_x>0$），接受概率 $a_x=c\,p_x/q_x\le1$，$c$ 取到使最大的 $a_x$ 等于 1；输出分布恰为 $p$；期望试 $\frac1{\sum_xq_xa_x}$ 次 |
