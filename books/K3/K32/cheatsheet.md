## K3.2 · 排序：比一比、挪一挪 · 速记表

| 提示 | 内容 |
|---|---|
| 循环不变量 | 一句话，每次进入循环时都为真。三步：初始化（第一次进入前为真）、保持（做完一轮仍为真）、终止（结束时把终止条件代进去得结论）。就是归纳法套在循环上 |
| 插入排序 | 左边是已排好的前缀，每轮把 `key` 插进去，比它大的右移。不变量：`A[1..j−1]` 是原来前 $j-1$ 个数且已排好。右移总数 $=\operatorname{inv}(A)$ |
| 选择排序 | 每轮选出剩余的最小者换到前面。不变量：前 $k-1$ 个是全体最小的 $k-1$ 个且已排好。比较数固定 $\frac{n(n-1)}2$，不稳定 |
| 逆序对 | 下标 $i<j$ 且 `A[i] > A[j]` 的数对；数法：每个数右边比它小的个数相加。排好为 0，倒序最多 $\binom n2$ |
| 相邻交换与逆序对 | 交换相邻两数，$\operatorname{inv}$ 恰好变 1，所以只靠相邻交换的排序至少 $\operatorname{inv}$ 次；冒泡的交换数等于 $\operatorname{inv}$。"相邻"不能去掉：交换不相邻的两数，一次可以消去许多个逆序对 |
| 插入排序的三种情况 | 时间 $\Theta(n+\operatorname{inv})$；最好 $\Theta(n)$（已排好），最坏 $\Theta(n^2)$（倒序），平均逆序对 $\frac{n(n-1)}4$（$\pi$ 与倒序 $\pi^R$ 配对，逆序数相加为 $\binom n2$） |
| 归并 | 合并两个有序数组：每次取队头较小者，比较至多 $p+q-1$ 次。排序：$T(n)=2T(n/2)+\Theta(n)=\Theta(n\log n)$，三种情况相同，额外空间 $\Theta(n)$，稳定（相等取左边） |
| 快速排序 | 取基准 `A[r]`，`PARTITION` 比较 $m-1$ 次分成两堆。不变量：`A[p..i] ≤ x`，`A[i+1..j−1] > x`。平均 $\Theta(n\log n)$，已排好的输入（取末尾为基准）最坏 $\frac{n(n-1)}2$；比例固定的失衡划分仍是 $n\log n$；不稳定 |
| 堆 | 数组当完全二叉树，孩子 $2i,2i+1$，父亲 $\lfloor i/2\rfloor$，最大堆：父不小于子。下沉至多 $\lfloor\log_2 n\rfloor$ 次交换；建堆从 $\lfloor n/2\rfloor$ 到 1；堆排序 $\Theta(n\log n)$，就地，不稳定 |
| 比较排序的下限 | 决策树叶子 $\ge n!$，高度 $h\ge\log_2 n!=\Theta(n\log n)$。$n=3,4,5$ 至少 $3,5,7$ 次。只对"只靠比较"的算法、且是最坏情况成立 |
| 计数排序 | 键是 $1..k$ 的整数：计数、累加、从右往左放。时间与空间 $\Theta(n+k)$，稳定；不比较，所以不受下限限制，$k$ 太大就不划算 |
| 稳定性 | 键相同的记录保持原有次序。稳定：插入、冒泡、归并、计数；不稳定：选择、快速、堆。两遍稳定排序（先次要键、后主要键）可完成多键排序 |
